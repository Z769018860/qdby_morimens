# 死亡调查报告 · 案件 01《第七站十夜游戏》

终端风格的文字推理游戏（灵感：Type Help 式的“残缺终端逐步恢复”与“调查报告”式的案卷推理）。纯静态页面，无需构建。

```bash
python3 -m http.server 8766      # 打开 http://localhost:8766/casefile/
node --test casefile/tests       # 引擎与案件数据测试
```

## 玩法
- 一开始终端只剩 `help / ls / cat / cd / pwd`。读到的档案会让更多指令恢复：`who`、`ask`、`show`、`board`、`note`、`grep`、`decode`、`open`、`accuse`。
- `cat` 读文件（可只写前几个字母，或直接写人名）；`ls -a` 看隐藏项；点击输出里的路径可直接填入命令；Tab 补全、↑↓ 翻历史。
- 有的文件加了锁（`open 文件 密码`，密码要从别的档案里找），有的是密文（`decode`，需要先读到码本）。
- `ask 人 话题` 问话，`show 线索 人` 出示线索看反应。谎言只有在你握有相反证据时才会被记成「矛盾」线索。
- `board` 是线索板；`hint` 给渐进式提示（会影响评级）；`accuse` 提交报告：凶手、手法、动机、三条关键线索，最多 3 次机会。
- 自动存档在浏览器本地（localStorage）；`restart` 重新开始。

## 结构
```
index.html  css/term.css  js/ui.js        界面（终端渲染、补全、存档）
js/engine.js                              纯逻辑引擎：指令解释、线索、问话、提交判定（无 DOM）
data/case1.js                             案件数据：文件、人物话题与出示反应、线索、提示、答案
tests/engine.test.mjs                     数据完整性、可解性（排除法）、逐步解锁、完整通关
```
新案件只需要再写一份 `data/caseNN.js`（同样的数据结构）。测试会检查：所有引用都能解析、每条线索都能拿到、密文能还原且不含汉字、每个密码都能从可读文件里找到、**可达证据恰好排除所有无辜者并只剩凶手**，以及一条完整通关路径。

故事与人物均为虚构（借用“融蚀 / 唤醒体 / 银钥”的世界观氛围），与官方无关。
