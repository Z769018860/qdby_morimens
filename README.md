## 构建与运行

页面源文件在 `src/pages/`，**不要直接改根目录的 `.html`**——那六个文件是构建产物。
改完源文件后：

```
node scripts/build.mjs
```

它会做这几件事（都是为了把首屏请求数压到最低，见下面的「为什么有构建」）：

1. 把每个页面的 ES 模块依赖图打包成 `js/b/<页面>.js`（10 个请求 → 1 个），
   整包套一层 async IIFE——产物里没有顶层 await，Chrome 61+ / Safari 11+ 都能跑
   （顶层 await 要 Chrome 89+ / Safari 15+，微信内置浏览器和 iOS 14 就死在这一点上）
2. 把 `css/style.css` 内联进 HTML（去掉一个阻塞渲染的请求）
3. 把造物标签 / 关键词 / 题库索引合成 `data/boot.json`，字典单独放 `data/dict.json`
   （原来挤成一个 918KB 的文件；现在 124KB + 772KB 并行，而且只有侦探 / 图鉴 / 工坊 /
   个人中心四页会下字典，其余页面一个字节都不下）
4. 把「合成大杜勒」的 10 张头像读成 data URI 塞进 `js/merge-art.js`（10 个请求 → 1 个）
5. 把「校猫的结合」的 72 张素材（校猫、34 造物、8 密契、10 钥令、8 首领立绘、9 种怪物，
   清单在 `data/binding-art.json`）读成 data URI 塞进 `js/binding-art.js`（72 个请求 → 1 个，约 407KB）
6. 把 `js/merge-sync.js`（合成大杜勒的账号同步件）单独打成一个延迟加载块，
   页面空闲时才 `import()`，不占首屏请求
7. 生成 `sw.js`，用构建戳做版本号（`src/partials/boot.html` 也在哈希里）

本地预览（纯静态，需要用 HTTP 服务器打开，`fetch` 读 JSON）：

```
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

要连同点赞、账号档案、云题库一起调试，起自带的后端（见 `server/README.md`）：

```
SERVE_STATIC=1 PORT=8795 node server/node.js
```

## 首页：评分、反馈、公告

首页（`src/pages/index.html`）除了项目列表，还挂了四件社区相关的事：

- **评分**：每张卡片可打 1–5 星 + 一句短评，卡片上显示综合分（所有人平均分）与人数。
  一人一游戏一条记录，重复提交就是改分。登录用 uid、没登录用本机随机 id，
  都存在 `zjtt:device`，所以清缓存前分数不会重复累计。
  后端两个实现同步维护：`edge-functions/api/[[default]].js`（EdgeOne **Blob**，
  键前缀 `hragg_` / `hrv_` / `bug_`；跟赞数、档案、题库共用同一份 Blob，**不需要另开 KV 命名空间**）
  与 `server/worker.js` + `server/schema.sql`（D1，表 `home_ratings` / `home_bugs`）。
- **BUG 反馈**：弹层里选游戏 + 写现象 + 留联系方式，提交成功会给一个 `B-XXXXXX-XXX` 编号。
  后端没连上时自动降级成「复制正文」与「去 GitHub 开 issue」，不会让反馈掉在地上。
- **公告**：进站弹一次，关掉后按版本号记在 `zjtt:noticeSeen`，同一版本不再打扰。
- **链接**：官网 / Steam / Discord / 忘忘看报，居中一排；页脚是数据来源与权利说明，
  和忘忘看报同源同口径（CC BY-NC-SA 4.0 + 素材版权归原权利人）。

## 离线版（PWA）与桌面版（Electron）

两条路，内容完全一样，共用同一份清单 `data/offline.json`（构建时由 `scripts/build_offline_manifest.mjs` 扫出来）。

**网页离线版**：`offline.html` 点「下载离线包」，把清单里的文件按 6 路并发灌进
`CacheStorage` 的 `zjtt-offline-v1`。`sw.js` 除了 `offline.html` 自己以外一律先查这个缓存，
所以断网后整站照常跑；`activate` 时也刻意不清它。装到桌面靠 `manifest.webmanifest`
（`start_url` 是首页，`display: standalone`）。

**桌面版**：`scripts/build_desktop.mjs` 把同一份清单同步到 `desktop/web`，
再由 electron-builder 打成 `desktop/dist/忘忘同人小游戏-v<版本>-win-x64.zip`：

```
node scripts/build.mjs              # 先出站点
node scripts/build_desktop.mjs       # 同步 + 打包（第一次会下 electron，几百 MB）
node scripts/build_desktop.mjs --dir # 只出未打包目录，调试用
```

主进程用自定义协议 `app://local/` 发文件（`file://` 下 ES module 与 `fetch` 都会被 CORS 拦掉），
除「检查更新」拉一次 `desktop/latest.json`（几 KB）外不发任何请求；窗口位置大小记在 userData。
更新清单在 `desktop/latest.json`，发版时改版本号 + 传新包即可。

> electron-builder 的 `zip` target 会为了签名去下载 winCodeSign（里面含 macOS 符号链接），
> 普通权限下解压必然失败，所以我们自己用 `7za` 压 `win-unpacked`，反正本来就不签名。

**存档**：`offline.html` 的「导出 / 导入」把本机 `localStorage` 里属于本站的键
用 AES-GCM 256 加密成 `.zjtt` 文件（PBKDF2-SHA256，20 万次迭代，盐与 IV 都随机写在文件头），
密码只在用户手里、解密在本机做，文件不上传。桌面版与网页离线版通用。

## 横屏 / 竖屏

七个游戏页共用 `src/partials/orient.html`（构建时注入到 `</body>` 前）：左下角一颗三档开关
（自动 / 横屏 / 竖屏），记在 `zjtt:orient:<游戏>`，各游戏互不影响。
能锁就调 `screen.orientation.lock`（需要全屏，所以用户点的那一下顺手全屏）；
锁不上（iOS Safari、桌面浏览器）且手机竖着时给一层「把手机横过来」的提示，
可以选「已经横过来了」或「仍要竖屏玩」。切完补发 `resize`，canvas 游戏会自己重排。
挂机版与死亡报告是独立子项目，各自内联一份（`idle/src/ui/orient.js`）。

### 为什么有构建

线上跑在腾讯 EdgeOne Pages：静态响应头是 `Cache-Control: max-age=0, must-revalidate`，
且只提供 HTTP/1.1。实测**每个请求固定 1~2 秒，跟文件体积几乎无关**——所以首屏慢的原因
是请求个数，不是字节数。构建把首屏从 23 个请求压到 4~5 个，`sw.js` 再把回访变成
「本地读取」，跨页切换从 4 秒降到 0.3 秒。

## 数据

数据由 [qdby_chinese](https://github.com/Z769018860/qdby_chinese) 生成：

```
python3 scripts/build_data.py /path/to/qdby_chinese [--seasons 71 72] [--per-season 500]
```

依赖：Python 3 + Pillow。题目来自第 71、72 期融灾榜单；玩家 UID 已去除，每人每区域只取一场。

## 校猫的结合：剧情、设定集与声音

这一页的剧情不是几句氛围文案，是一整条能读完的线：进门前有开场、每层下来有过渡、八个首领出手前各有一段、打完前七层各有一段、通关还有一段，共 25 场、148 句话，用打字机逐字推进，`h`/空格翻页、`Esc` 跳过。

- **文本出处**：世界条目、造物密契钥令的档案句，都取自本机提取的官方剧情与档案包（1248 段组 / 50457 条 AVG 台词 / 1174 条收藏馆条目 / 77 位唤醒体档案）。带专名的设定一律照原文改写，例如「银芯」用的是收藏馆原句「生命被融蚀侵蚀后，极小的概率会析出一种类银物质」。
- **同人的部分**：校猫掉进八层地下、最后从天台爬出来的那一夜，是我按原作规则新写的。**怪物不是**——一层的提灯教众 / 融蚀野犬 / 协作型融蚀体，二层的手术医生 / 蜡像绅士 / 双生脓疱，三层（蜡像馆）的蜡像绅士 / 手术医生 / 双生脓疱 / 「永恒助祭」，四层（天台，精英）的奔袭之足 / 「永恒助祭」/ 维度猎手，五层（锅炉房）的手术医生 / 双生脓疱 / 维度猎手 / 奔袭之足，六层（大礼堂）的蜡像绅士 / 「永恒助祭」/ 维度猎手 / 奔袭之足，七层（礼拜堂）的「永恒助祭」/ 奔袭之足 / 维度猎手 / 双生脓疱，八层（深渊）的奔袭之足 / 维度猎手 / 「永恒助祭」/ 双生脓疱，以及八个首领「守灯人」「劳伦斯先生」「查泰德夫人」「以眼还眼」扳手杰克逊「大魔术师霍迪妮」「审判」的使徒「万物寂灭」，全部是游戏自带图鉴里的条目（`data/boot.json` 的 `dict.monster`，id 13956 / 13958 / 14047 / 13986 / 14116 / 23774 / 44480 / 13976），名字、英文名、图鉴描述照原样，立绘用图鉴那张 `Portrait_Small_Monster_*`；只有数值、AI 和首领招式是地牢需要的（原作是回合制）。设定集里每条都标了分类（地点 / 世界 / 民俗 / 猫），有出处的照原作写，新写的只用原作已经给出的规则推导，没有另起一套设定。
- **主角就叫弥萨格校猫**：不是小煤球。「小煤球」在设定集里保留成一条**名号**条目（谁在校门口待得最久谁就是，前两代还是海獭），这一代校猫不答应这个称呼——正文里写明了这一点，台词与说话人栏一律用「弥萨格校猫」。
- **设定集**（标题页「设定集」或暂停菜单里打开）：20 条世界观 + 52 件藏品档案（34 造物 + 8 密契 + 10 钥令）。解锁条件复用关卡进度（走到第几层、清过几关、杀过几个首领、通关过没有），开局就能读 4 条最基础的（弥萨格、融蚀、银芯、小煤球那个名号）。
- **背景不是图**：走廊 / 解剖教室 / 蜡像馆 / 天台 / 融蚀深渊 / 天亮 / 标题校舍七个场景，全是 canvas 现场画的（透视盒子 + 光 + 固定种子的随机），同一段代码在 390 宽的手机和 1440 宽的桌面上都成立。加一张背景图就多一次 1~2 秒的边缘往返，这个页面到现在仍然只有 **HTML + 一个 bundle** 两个请求。
- **声音**：18 个音效 + 7 首循环 BGM（标题 / 走廊 / 教室 / 蜡像馆 / 天台 / 首领 / 天亮），用 WebAudio 振荡器与噪声按小节合成、前瞻调度，没有任何音频文件；暂停与对话时自动压低音量。

## 中文化与关键词

- 命轮、密契、钥令、造物、怪物的中文原文来自游戏数据；缺失的造物名称/描述优先取游戏配置（`replay-relic-config.json`），其次取同名基础版本，最后才用人工译文（`scripts/i18n/zh/misc.json`）。
- 唤醒体技能、天赋、启灵、衍生卡牌共 998 条文本模板、829 个名称，以及 100 个全局关键词的说明，原文只有英文。中文由本项目翻译（AI 辅助，**尚未经官方文本校对**），保存在 `scripts/i18n/zh/`；已有的官方/社区译名（`qdby_chinese` 词表、计算器内置的技能名）优先，并保留英文原名。若之后拿到游戏内的中文文本，只需用同样的键覆盖对应文件再重新构建即可。
- 文本里的状态/机制（力量、侵蚀、易伤、吞噬、界域……）以 `⟦slug|文字⟧` 标记，页面渲染成带图标的标签，悬停显示说明、点击展开详情。
- 图鉴支持按关键词筛选：唤醒体（技能/天赋/启灵描述）、命轮、密契、钥令、造物、怪物的描述中包含该关键词即命中，可多选（同时包含/任一）。筛选状态写在地址栏，可直接分享，例如 `codex.html#tab=wheel&kw=poison,counter&mode=any`。
- 新增/更新文本的流程：`python3 scripts/i18n_extract.py /path/to/qdby_chinese`（只追加新条目）→ 在 `scripts/i18n/zh/` 补译 → `python3 scripts/build_data.py /path/to/qdby_chinese`。

## 设计取舍与限制

- **答案不明文**：`data/puzzles.json` 里只有公开线索，答案用 `js/pepper.js` 里的密钥混淆封装、进入题目时才在浏览器里解开。这能避免随手翻看，但纯静态站不可能真正防作弊。
- **辅助位不唯一**：同一份战报可能对应多种合理辅助，因此：①题库只收每名成员都有伤害/格挡/治疗之一的战报；②额外给出每位成员的「卡牌升级次数」「天赋合计」作为线索；③评分按字段命中率计算。
- **区域 Boss**：来自客户端配置导出的节点数据；第 71/72 期的区域 3 缺少节点数据，因此该区域的题目没有 Boss 线索。
- **翻译质量**：技能、天赋、启灵与关键词说明的中文是译文，可能与游戏内措辞不完全一致；个别带 `※` 的数值表示数据源没有给出具体数值。
- **未上榜条目**：50 个「摆锤」、46 个事件造物等从未出现在榜单队伍里，没有已知的游戏 ID；它们在选择器里标记「未上榜」，可作干扰项，但不会是答案。
- **关键词图标**：数据源只有 72 个关键词带图标，其余用颜色与文字徽标代替。
