    忘却协议

    六边形防线 · 自走棋 · 《忘却前夜》同人

    • 布阵：在左侧四列六边形格子里摆唤醒体，影怪从右侧通道一格一格走进来 —— 备战期棋盘上就标好了下一波从哪几条通道来、来的是什么。每局地格不一样，高台 / 祭坛 / 裂隙站上去有加成，岩壁站不了人，影怪也过不去。
    • 商店：62 名唤醒体，每波结束免费换一批；同一名买三个合成 2 星，再三个合成 3 星，升星送命轮 / 造物。
    • 装备：切到「命轮·造物」页签买装备，点装备栏里的一件再点唤醒体就装上。命轮是纯数值，造物带机制（反伤、追击、回血……）。
    • 羁绊：20 条，分四类 —— 界域（血肉 / 深海 / 混沌 / 超维）、职阶（伤害 / 防御 / 辅助）、组织（愚者结社 / 外乡人 / 混血 / 不可知者 / 群星 / 永恒 / 无所属）、流派（触手 / 剧毒 / 吞噬 / 穿刺 / 反击 / 胚胎）。凑够人数就生效，左侧面板按这四类分组列。
    • 商店：刷新只要 1 金；能三合一的那张卡会呼吸式高亮并挂「升星」角标，同名凑够两个的挂「同名×n」。
    • 词条：选中唤醒体后，卡里的属性名（生命 / 护甲 / 攻速……）与「机制」小标签都是按钮 —— 点一下就地展开说明：怎么算、什么时候有用、谁提供。想看全部 33 条，点底栏的「图鉴详情」。
    • 目标：守住十二波，漏怪扣协议核心，核心归零就结束。

    玩法说明

    照着打两波就懂了，这里只写容易漏的

    • 操作：点商店买人 → 自动落到合适的空格（人满就进备战席）→ 点备战席上的人再点格子可以挪位置，点人再点空格可以换位；反过来点场上的人再点备战席的格子，就是收回备战席（那个格子有人就两人互换）。
    • 射程：选中一个唤醒体，棋盘上会画出它的攻击范围；人在备战席时，把鼠标移到格子上就能预览「放在这里打得到哪」。
    • 来敌：备战期棋盘右侧的紫格标出下一波的入口，虚线是它们要走的路线，格上画着头像和数量（左侧面板里也列了一遍「哪条通道、什么怪、几只」）。影怪一格一格走，不会直线穿过棋盘。
    • 装备：点「命轮·造物」页签买，买进装备栏 → 点装备栏里的一件 → 点棋盘上的立绘（或备战席头像）装上；点信息卡上的装备格可以卸下。一个唤醒体各带一件命轮、一件造物。
    • 合成奖励：合成 2 星给 +1 金与一件随机命轮，3 星给 +2 金、一件随机造物和一个独立额外商店；原商店保留，可随时返回。升级人口返 1 金，不刷新任何商店。
    • 卖出：选中单位后按 E，或点信息卡上的「卖出」。1 星原价退，2 星 3 倍，3 星 9 倍，身上的装备会退回装备栏。
    • 人口：上场人数上限就是等级，升级固定 5 金，最高 8 级。等级越高，商店里高费唤醒体越常见。
    • 狂气：每条紫色狂气条攻击和挨打都会涨，满了自动放大招；站在祭坛上攒得快，带活性注射器更快。六种大招各有各的样子和声音 —— 落雷从天砸一道光柱、冲击波炸开三层环、护罩扣一层六边形玻璃罩、加速甩出横向速度线与箭头、眩晕扩散电波与星芒、治疗升起一串光点。
    • 经济：每清一波给 4 金，手里每存 5 金额外给 1 金（最多 5 金）。存钱升人口是这套玩法的核心。
    • 顶栏按钮：1×/2× 切倍速（记在本机，下一局还是这个速度，判定不变、只是每帧多推几步）；♪ 开 / 关声音（音效与 BGM 都在浏览器里现场合成，不额外下载音频文件）。
    • 声音：38 种音效 + 7 段 BGM，全在浏览器里合成。BGM 跟着进度换——备战慢 62bpm、前六波 96bpm、第七波起加密到 112bpm（多一层十六分琶音）、首领波降到 84bpm 走三全音、末波换成最高张力的一首、结算按胜负分开。音效里比较值得听的有：利息升一档（金币池下面那行小字跳档时）、狂气满放大招（先一声蓄力铃，再上这个流派自己的音色）、护盾吃掉伤害、核心掉到 5 以下的两声闷响、首领登场那记低音、升 2/3 星的琶音、结算时八项数字逐条落下的刻度声。
    • 快捷键：空格开战 / R 刷新 / F 升级 / E 卖出 / Q 放回备战席 / Esc 取消选中。
