# 挂机前夜

《忘却前夜》（Morimens）**非官方同人**挂机自动战斗小游戏。免费、非商业。角色与美术素材版权归原权利方所有；数值与技能效果为本作自行设计。

当前进度：**M0–M17（完整可玩：真实技能/状态、挑战、周 Boss、属性塔、竞技场、银芯经济、注册福利、战斗特效、详细结算、叠位/突破、原作钥令、一键配队、手动挂机、通关回合上限与前后排、挂机收益随关卡成长、预设编队、程序化 BGM、抽卡记录与欧非评估、按模式的挑战编队、挑战观战回放、唤醒体多键排序、五队齐上的融灾禁区、挂机层默认取有收益的最高层、社区主播联名彩蛋与「星辉直播间」活动）**。

## 玩法
- **五个分组**：底部导航按功能域分成 战斗 / 养成（队伍·唤醒体·命轮密契·钥令）/ 召唤 / 挑战（无限塔·周 Boss·属性塔·竞技场）/ 更多（签到·图鉴·成就·设置），组内有多个页面时用顶部胶囊切换，组内会记住上次停留的页。
- **新手引导**：首次进入会逐条高亮底部各分组，说明每一块能做什么，最后一步直接带你去领注册福利；之后可在设置页重看。
- 4 人小队全自动战斗：每人 7 个技能槽（攻击/防御/技能一/技能二/唤醒/共鸣/超共鸣），共鸣与超共鸣能量满后自动释放。
- 推图挂机（每 10 关一个 Boss），离线最多结算 8 小时；**没有倍速、也没有「极速跳关」**，战斗按一套固定节奏播放。
- **挂机收益面板（M9 / M12）**：战斗页顶部并排显示「当前关 / 下一关」的每小时金币、召唤券、银芯、装备、胜率与战力，下一关还会标出相对涨幅。一场按 25 秒计、每小时 144 场；金币跟关卡走，召唤券与银芯的基础掉率是 40 场 1 张 / 90 场 1 枚，**并随关卡缓慢提升**（每深一关 +1.8% / +2.6%，第 60 关约 2.1× / 2.6×），两列下方直接写着「关数加成 券 ×2.26（18 场 1 张）」；零头累进 `state.drip` 并在结算里显示进度，所以面板上的数字既是离线预估也是在线实收。
- **手动挂机（M10 改语义）**：右上角关掉「自动挂机」后战斗照常连打，但**不再自动往前走**——只更新最高通关，永远停在你选的那一关反复刷，输了也不会被退回；换关卡用右上角 ◀ ▶ 自己走过去。（M9 的「开战、赢了直接推进到 `最高关 + 1`」已删除：那条路能让没通关的关卡被跳过，收益和进度脱节。）
- 62 名唤醒体、149 命轮、21 密契（套装 2/4 件）、310 造物、**63 件原作钥令**，召唤带保底，重复获得提升**叠位**。
- 战斗策略预设：均衡 / 强攻 / 稳守 / 集火强敌。存档在浏览器本地，可导入导出。
- **完整立绘**：唤醒体详情里的立绘用的是官方素材 `assets/card` 的 240×600 原图（不是列表里的缩略头像），点立绘可全屏查看，背景压暗后独占视野。
- **真实技能名与文本**：62 名唤醒体的 7 个技能槽使用原作卡牌名称与中文说明（译文），再按其中的关键词（中毒、易伤、反击、屏障……）附加本作效果；敌人的招式同样来自原作怪物的技能文本。
- **状态系统**：中毒、出血、易伤、虚弱、反击、力量、屏障、护垒、脆弱、封印，战斗中显示带图标的状态，点击查看原作关键词说明。
- **真实怪物设计（M4）**：537 个怪物（267 普通 / 107 精英 / 163 首领）直接取自游戏客户端怪物表——官方译名、血量/攻击/防御系数、体型、特征，以及**开场出招序列 + 循环出招序列**；每个招式按客户端公式（`攻击力×系数`、命中次数、层数、回合数）换算成战斗效果，敌人头顶显示**意图图标**与下一招；点击敌人查看出招表。新增「图鉴」页（搜索 / 阶级 / 特征筛选、遭遇与击败记录）与 3 个图鉴成就。
- **更细的数值**：唤醒体技能读取原文里的数值区间（如 `150–300%攻击`、`10–20%防御护盾`、`5–10 点狂气`），与同槽位中位数相比后缩放本作效果，并按「技能等级 Lv.1–5」（随角色等级与★提升）插值；详情页显示「原作数值 → 当前」。
- **音效（M13 重做）**：全部由 WebAudio 实时合成（无音频文件）——命中音色随界域变化、暴击/格挡/反击/中毒/治疗/护盾/增减益/倒下/共鸣/Boss 登场/胜负/召唤/成就/金币/不可用/解锁/盖章，同类音效做了微失谐，连打几十下也不会变成复读机；抽卡结果按「精良 / 史诗 / 创生」三档给不同揭晓音。
- **背景音乐（M13）**：六首程序化小曲（静夜·城镇 / 夜行·推图 / 交锋·战斗 / 威压·首领 / 共鸣·召唤 / 攀登·挑战），每首都是「和弦进行 + 低音 + 琶音 + 主旋律 + 轻打击」的实时演奏：用 16 分音符 step sequencer 预排 0.3 秒、按 AudioContext 时钟对齐（不受 JS 定时器抖动影响），和弦按调式音阶叠三度生成所以永远在调内，琶音左右轻微摆开、过一遍低通听起来更像背景而不是音效。切页面自动换曲并交叉淡入淡出，战斗遇到 Boss 会切「威压」；设置页可以锁一首或恢复「跟随页面」，顶栏喇叭一键静音。
- **周 Boss（M5）**：每个 ISO 周从真实首领中固定抽一个，每天 3 次、每次只打 12 回合比拼伤害，周累计伤害解锁 8 档里程碑奖励，周一（UTC）换 Boss。
- **属性塔（M5）**：混沌 / 血肉 / 深海 / 超维四座塔，只允许对应界域的唤醒体进入（自动选最强 4 人），敌人优先取带对应界域特征的怪物；逐层挑战，首次通关给奖励。
- **竞技场（M5）**：**1000 名人机天梯**（M10 从 100 扩到 1000；队伍由名次确定性生成，越靠前越强，每日 5 次 + 每日排名奖励）；**好友对战**：生成「对战码」发给好友，好友粘贴即可挑战你当前的队伍（反之亦然）。对战码是队伍快照，不需要任何服务器，不限次数、无奖励，只记录胜负。
- **银芯（M6）**：新的货币 💠，来自首通（普通 4 / Boss 20）、首杀新首领、成就、签到、周 Boss 里程碑、属性塔、竞技场与分解装备。用途：银芯召唤（200/抽，十连 1900，与召唤券共用保底）、精选祈愿（SR 以上装备）、**装备精炼**（最高 5 阶，每阶 +8% 该装备全部加成，分解返还一半）、银芯商店（召唤券 / 金币 / 装备 / 各玩法额外次数，每日限购）、补签。
- **签到**：月历（UTC 月），每天一次、7 的倍数日奖励翻倍并送装备，6 档累计宝箱，漏签可补。
- **成就**：从 25 个扩充到 100+ 个，分 11 类（推图 / 战斗 / 收集 / 养成 / 装备 / 召唤 / 挑战 / 竞技 / 图鉴 / 签到 / 总览），阶梯式奖励（召唤券 + 银芯 + 金币），支持一键领取。
- **注册福利（M7）**：在项目首页登录 / 注册账号后（游戏读取同源 localStorage 里的账号名，不联网），到「签到」页领取一次性福利：银芯 1000 + 召唤券 10 + 金币 5000 + 装备 ×1，并解锁 **7 日新手福利**（每天银芯 100–300 + 召唤券，错过的可在之后 7 天内补领）。同一账号只领一次，换存档不会重复；这是客户端「君子协定」，清空浏览器数据会重置。
- **战斗特效（M7）**：画布特效层——命中斩击 + 冲击环 + 火花（颜色随攻击者界域）、攻击轨迹、暴击闪白 + 震屏、治疗十字粒子、护盾光环、增益 / 减益箭头、中毒气泡、出血、倒下粒子、共鸣 / 超共鸣爆发环与闪光、Boss 登场暗闪、胜利彩带；出手冲刺、受击增亮。设置页可选 完整 / 简化 / 关闭，默认遵循系统「减少动态效果」。
- **详细结算（M8）**：每场战斗结束生成评级（S/A/B/C/D 与 ★）、奖励明细（含银芯、首杀首领、新遭遇怪物）、十项总览（总伤害、每回合伤害、受击、治疗、护盾、暴击率、最高单击、击杀、共鸣释放、剩余生命），逐人数据（伤害占比条、承伤与盾挡、暴击率、最高单击、治疗、护盾、击杀、出手构成、持续伤害 / 反击 / 屏障 / 死扛，输出 / 承伤 / 治疗 / 最高单击 MVP），敌方数据（承受 / 造成伤害、受到的状态、倒下回合）和逐回合伤害时间线。设置里可选自动弹出时机（首通 / Boss / 新怪物时，默认；每场；从不）；弹出时战斗暂停，关闭后继续。融灾试炼、属性塔、周 Boss、竞技场的结算也使用同一份数据。
- **养成三条线（M9）**：**等级**（金币，`40×lv^1.45`，每 20 级一次「突破」——金币 4 倍下一级价 + 银芯 `20+lv`，不突破就升不动）；**叠位**（重复抽取 +1，上限 **99**：每 1 叠位 +1.5% 全属性且等级上限 +1，每 10 叠位 +3% 增伤，每 40 叠位技能等级 +1，最多 +2；0 叠位上限 60 级，满叠位 159 级）；**技能等级**（每 15 级 +1 档，最高 Lv.5）。详情页给出等级上限、当前叠位、每级成长、突破与叠位的材料消耗，「养成指南」把四页该做什么按顺序串起来。
- **造物 6 格与羁绊（M9）**：造物栏从 3 格扩到 6 格（最高通关 20 / 45 / 75 各解锁一格），只有已解锁格里的造物生效；同主题造物凑到 2 / 4 / 6 件触发羁绊（10 种主题：战意、生机、壁垒、星辉、蚀刻、回响、祝福、财富、引火、锋锐），例如「战意 2 件 +6% 攻击 / 4 件再 +6% 增伤 / 6 件 +15% 攻击 +12% 增伤」。队伍页直接显示每种主题差几件到下一档。
- **原作钥令（M10）**：第三件全队配置，改用原作 63 件钥令（R 42 / SR 15 / SSR 6）的名字、界域、图标（`public/img/key/KeyToken_*.webp`）与原文效果，加成映射到本作属性；3 个位置（通关 1 / 12 / 35 解锁），每件可用银芯「淬炼」到 5 级、每级 +15% 效果；同一件不能占两个位置。来源：Boss 首通、无限塔每 10 层、周 Boss 第 4/8 档里程碑、商店「钥令匣」，重复获得折 💠30。
- **命轮密契页与一键配队（M10）**：装备页改名「命轮 · 密契」，顶部是队伍 4 人 ×（命轮 / 密契）的槽位面板，点槽位直接换装，不用绕回角色详情；**队伍页在「一键配队」下方也放同一块槽位面板**，配完当场就能看到谁装了什么、密契套装凑到几件。队伍页的「一键配队」一次配齐 4 人队伍（含同界域加成）、每人的命轮与密契、已解锁格里的造物（优先凑羁绊）、3 个钥令位（按加成强度排序）。
- **无限塔 300 层（M10）**：爬塔上限从 150 提到 **300**；奖励金币按「等效关卡」封顶在第 200 层对应强度，层数照爬、钱不失控。
- **通关回合上限与前后排（M11）**：每场都有回合上限——普通关 **18 回合**、Boss 关 **22 回合**，打满还没清场直接判超时（不算通关、不推进），「四个奶互相吊着磨」这条路被堵死；战斗页显示「第 N / 18 回合」与关卡副标题「限 18 回合」，结算横幅区分「超时判负 / 全员倒下」。站位 1–2 是前排、3–4 是后排：敌方单体只打前排（Boss 例外，可越过前排），我方守护只能打敌阵前排、突击与合唱可以点名后排，前后排标签在队伍卡与战斗单位上都标了出来。
- **挂机收益随关卡提升（M12）**：推图挂机的召唤券与银芯不再是死值——基础 40 场 1 张 / 90 场 1 枚，之后每深一关 +1.8% / +2.6%（第 60 关约 2.1× / 2.6×、第 100 关约 2.8× / 3.6×），银芯涨得比券快。收益面板每列底部直接写「关数加成 券 ×2.26（18 场 1 张）· 银芯 ×2.82（32 场 1 枚）」，「下一关」那行同时给出金币 / 券 / 银芯三项涨幅；结算多一条「挂机零头：券 0.14 / 银芯 0.07」，能看见一场一场攒。离线结算走同一条曲线，小数余量也不再丢。
- **塔每层收益（M11）**：无限塔与属性塔每爬一层都给一点点召唤券与银芯，并随层数缓慢变多（前期一层不到 1 个、300 层爬满约多出 80 券 + 1200 银芯），零头存进存档攒到下次，5 / 10 / 20 层的里程碑奖励照旧。
- **校猫奖励首领（M10）**：推图每 40 关、无限塔每 20 层、属性塔每 20 层的 Boss 位换成「校猫」（弥萨格的**黑猫**，头像用「忘忘看报 · 爱的节奏榜」里那只戴礼帽的校猫，自带 5 条原创出招），打赢额外 +5 召唤券 +60 银芯 +1 装备，**首杀翻倍**，并配 3 个专属成就。
- **分页背景（M9 / M11）**：典藏馆 CG 压成 `public/img/bg/hall-01..36.webp`（36 张，约 610KB），14 个页面各配一张，切页时淡出淡入换图，叠一层渐变保证深色主题下的文字对比度；**战斗页另有一层章节场景底图**，随 `stageInfo().chapter` 在 6 张 CG 之间轮换。新增素材由 `tools/build_bg.py` 从 `assets/gallery` 自动挑选（够暗、横向、非纯色）并压到 900 宽。
- **编队与挑战阵容（M13）**：队伍页可以把当前 4 人存成 **一队 ~ 五队**（只记人——命轮与密契绑在唤醒体身上会跟着走，造物与钥令本来就是全队共用）；挑战页的每一项（无限塔 / 属性塔 / 周 Boss / 融灾 / 竞技场）顶部都有「出战阵容」条，可以各自指定用哪一套或跟随当前队伍，指到空编队会自动退回当前队伍。属性塔仍只收本界域成员（编队里的其他人会被剔掉）。推图挂机固定用「当前队伍」，点编队的「上阵」即可换过去。老存档自动补空位、剔除已不存在的唤醒体。
- **抽卡记录与欧非评估（M13）**：召唤页新增记录卡——累计抽数、创生 / 史诗 / 精良的数量与实际概率、平均几抽出一个创生、十连最好成绩、距保底还剩多少抽，以及一个 **幸运指数**：实际拿到的「货值」÷ 按公示概率该拿到的货值 × 100（创生记 100、史诗记 18、精良记 1，期望 10.26/抽），100 是平均水平，条形图上有一根 100 的参考线。评价分五档：欧皇降临（≥160）/ 血统纯正（≥120）/ 亚洲水平（85–120）/ 略显非气（55–85）/ 非酋本酋（<55）。「完整记录」弹窗按稀有度筛选明细，并给出每档实际概率与期望的偏差。明细只留最近 300 条，但累计统计是全程的，裁剪不影响指数。
- **挑战编队（M14）**：队伍页的「挑战编队」把 8 个入口一次列全——无限塔、混沌尖塔 / 血肉之塔 / 深海回廊 / 超维阶梯（四座属性塔各存一套）、周 Boss、融灾、竞技场——每行直接点「当前队伍 / 一队 ~ 五队」切换，头像与战力即时跟着变。每行的「编队」按钮会打开**现场编队**：四个槽位 + 界域筛选（全部 / 混沌 / 血肉 / 深海 / 超维），点候选头像加入、点槽位移出，顺序就是站位（前两个是前排）；「一键上阵」按当前筛选的界域取战力最高的 4 名（优先前排守护 + 治疗），存成任意一套后该模式立刻指向它。从属性塔进来时界域筛选会被锁在本界域（混沌塔只能上混沌唤醒体）。挑战页顶部也有一条同样的选择条，两处是同一份数据。
- **挑战观战（M14）**：挑战不再点一下就直接跳结算——先播一段战斗回放：双方站位、血条、共鸣/钥焰条、逐条战斗日志，命中飘字与音效都在。右上角可以 1× / 2× / 4× 加速，随时「跳过过程」直达结算。爬塔只回放决出胜负的最后一层（爬到几十层不会播几十场），属性塔连打时回放最后一场。设置页「挑战过程」可以改成「直接出结算」，喜欢快的人不必每次看。
- **唤醒体排序（M14）**：唤醒体页可按稀有度 / 战力 / 等级 / 叠位数 / 获取顺序 / 界域排序，再点一次当前排序键就反向（↓ / ↑ 写在按钮上）。未获得的一律排在后面，配合「仅已拥有」可以只看手里有的。卡面直接给出等级、叠位、类型与单人战力。
- **融灾禁区（M15）**：挑战页新增的终盘玩法，**一层要同时派五个队伍**——一队~五队在队伍页提前编好（只有 5 套，每套 4 人），分别对上这一层的第 1~5 组敌人，第 5 组是精英 / Boss。**5 场胜 4 场即通过**（留一队的余量，免得怪物组合的运气压过队伍强度），每层满状态、不继承血量，一次挑战最多连爬 10 层。塔高 **100 层**，每 10 层一个里程碑、每 25 层有校猫奖励战（钥令 + 券 + 银芯），打穿 100 层额外给 40 券与 600 银芯。**每两周换一期**：敌人按新种子重排、层数从头爬、每层奖励重发，历史最高层永久保留；每期新开时界面与回归里都能验证（周期按 UTC 天数整除 14 天，第 1 期从 2026-01-05 起算）。挑战过程同样走战斗回放，只回放「决定这一层」的那一场（失败的那队，或全胜时的第五队）。
- **挂机层默认取有收益的最高层（M16）**：收益 = 胜率 × 单场收益，胜率 0 的关就是零收益。可 `state.stage` 一直跟着「正在打的那一关」走，攻坚时挂机也跟着去——一旦这一关（或 `maxStage` 自己）打不过（侥幸首通、换过队伍、叠位被清、造物被卸），在线空转，**离线结算也一直是 0**。现在统一由 `farmableStage` 判定：从想打的关往下扫（每关试 2 场、最多 60 关），**第一个打得过的层就是这个账号真正该挂的层**，结果按队伍 / 养成 / 装备的签名缓存。离线结算按这一层算，领完收益顺手把挂机层切过去；自动挂机在前线失手、或在已通关的关上连输 3 场，也会退到这一层。战斗页当前关胜率 0 时标黄并给一颗「退回第 N 关挂机」的按钮，离线弹窗会说明「已按有收益的最高层结算」。手动挂机不参与自动退层（关卡是玩家自己选的）。同一版把游戏名从《忘却之夜·挂机录》改成《挂机前夜》。
- **联名嘉宾与「星辉直播间」（M17）**：把《忘却前夜》社区里 9 位主播——萨摩不耶、梦依流苏、爱丽丝、鼠王、魔龙_D、立誓0氪、夏茉琳、朝星、路过的耄耋——做成彩蛋唤醒体，**不进召唤池**，只从签到与活动拿：**累计签到 3 / 7 / 15 天**各送一位（跨月累计，老存档进游戏自动补发），其余 6 位在「更多 → 联动」的「星辉直播间」里用人气档位解锁。人气来自每日任务（在线战斗 20 场 +30 / 胜利 15 场 +30 / 首次通关 2 关 +40，UTC 日重置，**离线场次不算**）、推图里程碑（最高通关每 10 关 +10，最高 100 关）和签到（每次 +5），档位 60 / 140 / 240 / 360 / 520 / 700。技能一律按昵称意象手写（雪橇犬护盾、丝线织梦、兔子洞多段、鼠群瘟疫、龙息群伤、零氪回能、茉莉奶妈、星轨暴击、遛弯老人扛伤），数值压在史诗之下、初始四人之上，四界域 × 三类型都有人，凑得出同域加成。数据在 `src/core/creators.js`，活动在 `src/core/event.js`，头像立绘由 `tools/build_creators.py` 生成（支持 `--portrait/--card` 换成授权素材）。
- **挑战**：无限塔（每日 3 次，生命继承）、融灾试炼（第 71/72 期的真实区域首领，C 到 SSS 六档威胁）、25 个成就、新手引导、伤害 / 治疗统计。

## 运行
```bash
python3 -m http.server 8765      # 然后打开 http://localhost:8765/
npm test                         # 核心逻辑测试
npm run sim                      # 平衡机器人：贪心玩 4000 场并打印进度曲线
node tools/regress.mjs           # 无头 Edge 回归（需先把站点跑在 8777）
```
纯静态，无需构建。推送到 `main` 后由 GitHub Pages 工作流自动部署。

## 数据管线
`public/data/game-data.json` 与 `public/img/` 分两步生成（需要 Pillow）：
```bash
python3 tools/build_data.py --src ../qdby_chinese            # 角色、命轮、密契、造物、怪物
python3 tools/build_morimens.py --morimens ../qdby_main --chinese ../qdby_chinese   # 真实技能文本、关键词、融灾试炼
python3 tools/build_monsters.py --morimens ../qdby_main --chinese ../qdby_chinese    # 真实怪物表、出招序列、意图图标
python3 tools/build_orders.py                                                        # 原作 63 件钥令（名字/界域/效果/图标）
```
第二、三步读取《战报侦探》仓库 `main` 分支（`qdby_main`）里整理好的中文数据（`dictionary / official-terms / skills / keywords`），以及 `qdby_chinese` 的客户端怪物表 `data/morimens/maps/monsters.json`。图片已压缩为 webp 缩略图（总计约 6MB）。技能中文为 AI 辅助译文，数据来源 SKeyDB（CC BY-NC-SA 4.0），故本项目仅限非商业使用。
