# 挂机前夜

《忘却前夜》（Morimens）**非官方同人**挂机自动战斗小游戏。免费、非商业。角色与美术素材版权归原权利方所有；数值与技能效果为本作自行设计。

当前进度：**M0–M19（完整可玩：真实技能/状态、挑战、周 Boss、属性塔、竞技场、银芯经济、注册福利、战斗特效、详细结算、叠位/突破、原作钥令、一键配队、手动挂机、通关回合上限与前后排、挂机收益随关卡成长、预设编队、程序化 BGM、抽卡记录与欧非评估、按模式的挑战编队、挑战观战回放、唤醒体多键排序、五队齐上的融灾禁区、挂机层默认取有收益的最高层、社区主播联名彩蛋与「星辉直播间」活动、队伍页标签化与彩蛋角色的重复获取、前后排按固定槽位判位、造物精炼的可见数值与就地培养）**。

## 玩法
- **五个分组**：底部导航按功能域分成 战斗 / 养成（队伍·唤醒体·命轮密契·钥令）/ 召唤 / 挑战（无限塔·周 Boss·属性塔·竞技场）/ 更多（签到·图鉴·成就·设置），组内有多个页面时用顶部胶囊切换，组内会记住上次停留的页。
- **新手引导**：首次进入会逐条高亮底部各分组，说明每一块能做什么，最后一步直接带你去领注册福利；之后可在设置页重看。
- 4 人小队全自动战斗：每人 6 个指令槽（攻击/防御/技能一/技能二/共鸣/超共鸣）+ 1 个**登场技**，共鸣与超共鸣能量满后自动释放。
- **登场技（原「唤醒」）**：编队一进场就自动生效一次，**不占第一回合的动作**——加成一开场就挂在身上，第一回合就能真出手。以前四个人第一轮都在喊唤醒，等于白送对面一轮，而挂机通关是有回合上限的（普通关 18 / Boss 22），那一轮直接吃掉 1/18 的预算。内部 slot id 仍叫 `Rouse`，存档与卡面数据不用迁移；详情页把这一槽标成「登场技 · 登场即生效，不占回合」。
- **自动战斗按「牌面收益」出牌（不同角色不同打法）**：每次行动给手上每一张能用的牌估一个收益——伤害、治疗、护盾、增减益、控制、能量统一折算成**等效血量**，再乘角色定位权重（突击重输出、守护重减伤、辅助重治疗与增益），挑分最高的那张。空放（满血治疗、满盾再套盾、没有增益可驱散）自然得 0 分被伤害牌顶掉，所以**每位唤醒体都按自己那套牌（真实卡面决定效果、界域决定附魔、定位决定权重）自动换打法**，不用给 71 个人各写一套规则。另外三件事：① 会读敌人**明示的意图**（群攻 / 单体 / 重击）提前套盾、提前救人；② 斩杀牌优先挑「已在斩杀线以下、血最多」的目标，比例扣血牌挑**血条最厚**的；③ 大招和其它牌一起算分，治疗型大招在满血时会先捏着（最多捏两次），不再白扔一次行动。打分全程不掷骰子，同种子同战场指令序列唯一确定（观战回放要靠这个确定性：同一场重放出来必须一模一样）。
- **AI 体检工具**：`node tools/ai-bench.mjs [lv] [star]`（`BENCH_STAGES` / `BENCH_SEEDS` / `BENCH_OD` / `BENCH_LAW` / `BENCH_VERBOSE` 可调）——固定阵容与种子，逐角色跑同一批关卡，输出胜率、平均回合与全员均值，用来看「改出牌规则以后谁被坑了」。
- 推图挂机（每 10 关一个 Boss），离线最多结算 8 小时；**没有倍速、也没有「极速跳关」**，战斗按一套固定节奏播放。
- **挂机收益面板（M9 / M12）**：战斗页顶部并排显示「当前关 / 下一关」的每小时金币、唤醒券、银芯、装备、胜率与战力，下一关还会标出相对涨幅。一场按 25 秒计、每小时 144 场；金币跟关卡走，唤醒券与银芯的基础掉率是 40 场 1 张 / 90 场 1 枚，**并随关卡缓慢提升**（每深一关 +1.8% / +2.6%，第 60 关约 2.1× / 2.6×），两列下方直接写着「关数加成 券 ×2.26（18 场 1 张）」；零头累进 `state.drip` 并在结算里显示进度，所以面板上的数字既是离线预估也是在线实收。
- **手动挂机（M10 改语义）**：右上角关掉「自动挂机」后战斗照常连打，但**不再自动往前走**——只更新最高通关，永远停在你选的那一关反复刷，输了也不会被退回；换关卡用右上角 ◀ ▶ 自己走过去。（M9 的「开战、赢了直接推进到 `最高关 + 1`」已删除：那条路能让没通关的关卡被跳过，收益和进度脱节。）
- 62 名唤醒体、149 命轮、21 密契（套装 2/4 件）、310 造物、**63 件原作钥令**，召唤带保底，重复获得提升**叠位**。
- 战斗策略预设：均衡 / 强攻 / 稳守 / 集火强敌。存档在浏览器本地，可导入导出。
- **战斗记录小窗（M18）**：默认跟随最新，但**你一往上翻就自动锁定**（标题条变「🔒 已锁定」），之后新日志不会把画面拽走；右下角亮出「回到底部 ↓」，点一下回到最新、或点锁定按钮手动切回跟随。选择记在 `localStorage`，刷新后保持。想细看某一回合发生了什么、或者靠日志判定 AI 这一手为什么这么打，就靠它。
- **唤醒体编队角标**：队库（唤醒体页）每张卡左上角标出编队情况——「上阵」= 主线当前队伍，`一队 / 禁区三队…` = 只写在某套编队里，同时编进几套会跟「+N」，鼠标停上去列出全部（`core/squad.js` 的 `squadsOfSlug`，顺序固定：当前队伍 → 编队位）。详情弹窗里也有一行「编队」标签，没编入任何队伍的会写出来，方便找出闲置角色。
- **可领取红点**：底部导航的「更多」组、以及二级页签的「成就」「联动」上会亮红点——数量 = 成就可领取数 + 联动今日任务可领取数 + 推图里程碑是否可领（`main.js` 的 `badgeCounts` / `refreshBadges`）。领完立刻消失（每次渲染与切页都会刷新）。
- **完整立绘**：唤醒体详情里的立绘用的是官方素材 `assets/card` 的 240×600 原图（不是列表里的缩略头像），点立绘可全屏查看，背景压暗后独占视野。
- **真实技能名与文本**：62 名唤醒体的 7 个技能槽使用原作卡牌名称与中文说明（译文），再按其中的关键词（中毒、易伤、反击、屏障……）附加本作效果；敌人的招式同样来自原作怪物的技能文本。
- **状态系统**：中毒、出血、易伤、虚弱、反击、力量、屏障、护垒、脆弱、封印，战斗中显示带图标的状态，点击查看原作关键词说明。
- **真实怪物设计（M4）**：537 个怪物（267 普通 / 107 精英 / 163 首领）直接取自游戏客户端怪物表——官方译名、血量/攻击/防御系数、体型、特征，以及**开场出招序列 + 循环出招序列**；每个招式按客户端公式（`攻击力×系数`、命中次数、层数、回合数）换算成战斗效果，敌人头顶显示**意图图标**与下一招；点击敌人查看出招表。新增「图鉴」页（搜索 / 阶级 / 特征筛选、遭遇与击败记录）与 3 个图鉴成就。
- **更细的数值**：唤醒体技能读取原文里的数值区间（如 `150–300%攻击`、`10–20%防御护盾`、`5–10 点狂气`），与同槽位中位数相比后缩放本作效果，并按「技能等级 Lv.1–5」（随角色等级与★提升）插值；详情页显示「原作数值 → 当前」。
- **音效（M13 重做）**：全部由 WebAudio 实时合成（无音频文件）——命中音色随界域变化、暴击/格挡/反击/中毒/治疗/护盾/增减益/倒下/共鸣/Boss 登场/胜负/召唤/成就/金币/不可用/解锁/盖章，同类音效做了微失谐，连打几十下也不会变成复读机；抽卡结果按「精良 / 史诗 / 创生」三档给不同揭晓音。
- **背景音乐（M13）**：六首程序化小曲（静夜·城镇 / 夜行·推图 / 交锋·战斗 / 威压·首领 / 共鸣·召唤 / 攀登·挑战），每首都是「和弦进行 + 低音 + 琶音 + 主旋律 + 轻打击」的实时演奏：用 16 分音符 step sequencer 预排 0.3 秒、按 AudioContext 时钟对齐（不受 JS 定时器抖动影响），和弦按调式音阶叠三度生成所以永远在调内，琶音左右轻微摆开、过一遍低通听起来更像背景而不是音效。切页面自动换曲并交叉淡入淡出，战斗遇到 Boss 会切「威压」；设置页可以锁一首或恢复「跟随页面」，顶栏喇叭一键静音。
- **Love Live! 四首（可选）**：设置页「背景音乐」第二排另有四首联动曲——僕らは今のなかで / Snow halation / それは僕たちの奇跡 / 夏色えがおで1,2,Jump!。和 `js/ll/songs.js` 是同一套重编：bpm、主音、调式、副歌的和弦走向照原曲来，`mel` 里存副歌四小节的旋律（八分音符一个半音偏移，`null` 休止），`schedule()` 见到 `mel` 就按谱弹主旋律，没有谱的曲子仍走原来的「随机落和弦音」。**没有原曲音源**，全是振荡器现场合成。这四首不会自动出现，点一下锁住，点「跟随页面」回自动。
- **音量平衡（音效 vs 音乐）**：以前两条总线的系数是音效 ×1.7 / 音乐 ×0.8，同一个滑杆数值下音效比音乐响 9dB 左右，战斗连打几十下就把音乐压没了。现在两条总线都按「滑杆 100% ≈ 满幅」标定（`SFX_GAIN` 1.2 / `BGM_GAIN` 1.5，默认 65 / 55），并在主总线上加了一个限幅器（`DynamicsCompressor`，-14dB / 4:1），连打时的瞬态不会糊成一片、也不至于把音乐挤掉。设置页那行提示会告诉玩家「觉得音乐被盖住就把音乐拉到 65 以上」。
- **周 Boss（M5）**：每个 ISO 周从真实首领中固定抽一个，每天 3 次、每次只打 12 回合比拼伤害，周累计伤害解锁 8 档里程碑奖励，周一（UTC）换 Boss。
- **属性塔（M5 / M20）**：混沌 / 血肉 / 深海 / 超维四座塔，只允许对应界域的唤醒体进入（自动选最强 4 人），敌人优先取带对应界域特征的怪物；逐层挑战，首次通关给奖励。层数上限 **300 层**（M20 才给四座塔定下终点，之前是无限往上），每 **50 层**一份里程碑（券 15+5×档、银芯 150+50×档、装备 ×1），一次性、记在 `state.rtower[界域].marks`；登顶后按钮变成「已登顶」。
- **守护改动 + 解毒（0.12.6）**：① **反击盾**：守护盾没破时每挨一下攒 1 层反击（回合末清掉），盾被打穿则反击清空，之后每挨一下让下一次出盾 +10%（最多 5 层）；② **盾爆**：回合末把剩余护盾的 30% 砸向敌方全体（铁壁型守护仍走原来的反震+降防），并留 50% 护盾进下一回合；③ **站位**：前两个槽位受到的直接伤害 −8%，后两个槽位增伤 +6%（只给站位好处，不强制职业占位）；④ **双人羁绊**：突击 / 守护 / 合唱各新增「同类 2 人」一档小加成；⑤ **耐毒**：场上每有一位存活守护（最多 2 位），友方身上的毒层每回合多褪 10%，且毒层上限由 40 降为 28；⑥ 司疗的技能一与大招、守律的技能一带净化（解毒）。以上只对我方与竞技场人机生效，普通怪不吃。
- **游戏内更新公告（0.12.10）**：进游戏时（离线结算 / 新手引导之后）弹一次最新公告，弹出即记「已读」（`state.newsSeen`），全新玩家不弹；设置页有「更新公告」可翻看。**发版时在 `src/core/news.js` 的 `NEWS` 最前面加一条**（id 变了就会重新弹）。
- **词条说明新增「详细结算公式」（0.12.9）**：伤害乘区下面多六组可折叠的公式——面板属性（叠位 / 超限 / 法则三层乘数、生命攻防系数）、直接伤害全流程（含我方 ×1.6、浮动、狂暴、防御曲线、站位）、毒 / 流血 / 反击（毒在中毒者行动后结算、半量防御 ×1.2、层数上限）、治疗 / 护盾 / 吸血、守护机制（反击盾 / 蓄盾 / 盾爆 / 铁壁）、竞技场与周 Boss 奖励；每组附带数值例子。数字抄自 `battle.js` / `stats.js` / `constants.js`，改系数时要同步 `main.js` 的 `keywordGuide()`。
- **周 Boss 扩到 8 层（0.12.8）**：在原来 3 层之上新增第 4~8 层（攻击 ×2.0~3.4、防御 ×1.7~2.7，奖励 ×3.4 / 4.6 / 6 / 7.6 / 9.5，第 4 层狂暴、第 5 层坚壳、第 6 层起两者兼有）。解锁看上一层本期累计伤害：200 万 / 400 万 / 600 万 / 600 万 / 250 万。实测满养成（159 级 / 99 叠位 / 超限 99 / 法则 60）无装备队单次伤害：第 1~8 层依次约 134 / 104 / 72 / 75 / 54 / 48 / 17 / 7 万，中档队（100 级 ★30）打到第 4 层就只剩 1 万，深层是给装备成型后的队伍准备的。
- **登顶层**：登顶第 1 名后继续向上有 **1100 层「登顶层」**（名次 0、−1 … −1099，界面显示「登顶第 N 层」）。第 1 层约为第 1 名的 1.3 倍战力，第 100 层约 22 倍，第 1100 层约 260 倍（之后每层约 +0.25%）；候选对手领先 1/2/4/7/12 层，每过 100 层跨度 +1 档（最多 ×10）；首次踏上新层每层额外 +2 唤醒券 +40 银芯；每日排名奖励随层数最高 +10 券。人机属性上限放宽到 hp 5e7 / 攻防 5e6，保证最后一层不被削平。
- **毒结算时机（0.12.7）**：中毒从「每回合一开头」改为「中毒者自己行动结束后」结算（流血 0.12.11 起也改成流血者自己行动结束后结算，先于毒）。中毒的人先出手再掉血；实测整体胜率变化在 ±1pp 内，我方受到的毒伤约降 40%，毒队输出基本不变（平均回合 9.8→9.5）。
- **竞技场（M5）**：**1000 名人机天梯**（M10 从 100 扩到 1000；队伍由名次确定性生成，越靠前越强，每日 5 次 + 每日排名奖励）；**好友对战**：生成「对战码」发给好友，好友粘贴即可挑战你当前的队伍（反之亦然）。对战码是队伍快照，不需要任何服务器，不限次数、无奖励，只记录胜负。
- **银芯（M6）**：新的货币 💠，来自首通（普通 4 / Boss 20）、首杀新首领、成就、签到、周 Boss 里程碑、属性塔、竞技场与分解装备。用途：银芯召唤（200/抽，十连 1900，与唤醒券共用保底）、精选祈愿（SR 以上装备）、**装备精炼**（最高 5 阶，每阶 +8% 该装备全部加成，分解返还一半）、银芯商店（唤醒券 / 金币 / 装备 / 各玩法额外次数，每日限购）、补签。
- **签到**：月历（UTC 月），每天一次、7 的倍数日奖励翻倍并送装备，6 档累计宝箱，漏签可补。
- **成就**：从 25 个扩充到 100+ 个，分 11 类（推图 / 战斗 / 收集 / 养成 / 装备 / 召唤 / 挑战 / 竞技 / 图鉴 / 签到 / 总览），阶梯式奖励（唤醒券 + 银芯 + 金币），支持一键领取。

- **校猫奖励首领（M10）**：推图每 40 关、无限塔每 20 层、属性塔每 20 层的 Boss 位换成「校猫」（弥萨格的**黑猫**，头像用「忘忘看报 · 爱的节奏榜」里那只戴礼帽的校猫，自带 5 条原创出招），打赢额外 +5 唤醒券 +60 银芯 +1 装备，**首杀翻倍**，并配 3 个专属成就。

- **编队与挑战阵容（M13）**：队伍页可以把当前 4 人存成 **一队 ~ 五队**（只记人——命轮与密契绑在唤醒体身上会跟着走，造物与钥令本来就是全队共用）；挑战页的每一项（无限塔 / 属性塔 / 周 Boss / 融灾 / 竞技场）顶部都有「出战阵容」条，可以各自指定用哪一套或跟随当前队伍，指到空编队会自动退回当前队伍。属性塔仍只收本界域成员（编队里的其他人会被剔掉）。推图挂机固定用「当前队伍」，点编队的「上阵」即可换过去。老存档自动补空位、剔除已不存在的唤醒体。

- **唤醒体排序（M14）**：唤醒体页可按稀有度 / 战力 / 等级 / 叠位数 / 获取顺序 / 界域排序，再点一次当前排序键就反向（↓ / ↑ 写在按钮上）。未获得的一律排在后面，配合「仅已拥有」可以只看手里有的。卡面直接给出等级、叠位、类型与单人战力。

- **挂机层默认取有收益的最高层（M16）**：收益 = 胜率 × 单场收益，胜率 0 的关就是零收益。可 `state.stage` 一直跟着「正在打的那一关」走，攻坚时挂机也跟着去——一旦这一关（或 `maxStage` 自己）打不过（侥幸首通、换过队伍、叠位被清、造物被卸），在线空转，**离线结算也一直是 0**。现在统一由 `farmableStage` 判定：从想打的关往下扫（每关试 2 场、最多 60 关），**第一个打得过的层就是这个账号真正该挂的层**，结果按队伍 / 养成 / 装备的签名缓存。离线结算按这一层算，领完收益顺手把挂机层切过去；自动挂机在前线失手、或在已通关的关上连输 3 场，也会退到这一层。战斗页当前关胜率 0 时标黄并给一颗「退回第 N 关挂机」的按钮，离线弹窗会说明「已按有收益的最高层结算」。手动挂机不参与自动退层（关卡是玩家自己选的）。同一版把游戏名从《忘却之夜·挂机录》改成《挂机前夜》。
- **联名嘉宾与「星辉直播间」（M17）**：把《忘却前夜》社区里 10 位主播——萨摩不耶、梦依流苏、爱丽丝、鼠王、魔龙_D、立誓0氪、夏茉琳、朝星、路过的耄耋、白云出岫——做成彩蛋唤醒体，**不进召唤池**，只从签到与活动拿，而且**可以重复拿**——同一人再拿到就是叠位 +1（叠位上限 99，光靠银芯共鸣太贵）。**签到每累计 1 天发 1 份**，按固定顺序轮着给：先把十位补齐，全到手之后继续轮、每次给一位叠一级（跨月累计，老存档进游戏按天数一次补发）。活动在「更多 → 联动」的「星辉直播间」：人气每 100 点换 1 张**嘉宾征召券**，点嘉宾卡上的「征召 +1」消耗一张——没到手就是新角色，到手了就叠位 +1。人气来自每日任务（在线战斗 20 场 +30 / 胜利 15 场 +30 / 击败 40 个敌人 +40（卡关时自动退到低关刷也能完成），UTC 日重置，**离线场次不算**）、推图里程碑（最高通关每 10 关 +10，最高 100 关）和签到（每次 +5），门槛 60 / 140 / 240 / 360 / 520 / 700（签到那三位门槛 0，随时可换）。技能一律按昵称意象手写（雪橇犬护盾、丝线织梦、兔子洞多段、鼠群瘟疫、龙息群伤、零氪回能、茉莉奶妈、星轨暴击、遛弯老人扛伤），数值压在史诗之下、初始四人之上，四界域 × 三类型都有人，凑得出同域加成。数据在 `src/core/creators.js`，活动在 `src/core/event.js`，头像立绘由 `tools/build_creators.py --face-dir=tools/faces` 生成——用的是主播本人的 B 站公开头像（原图与来源记录都在 `tools/faces/`），立绘做成「圆形头像 + 竖排名字」的嘉宾名片；要换图直接覆盖 `tools/faces/<slug>.jpg` 或用 `--portrait/--card` 指路径。档案里的简介除萨摩不耶（简介为定制文案）外一律**照录主播本人的 B 站签名原文**（快照在 `tools/faces/source.json`），不替人编造人设；社区外号（如萨摩不耶「一哥」、路过的耄耋「安卓佬」）只作为标签显示。每位主播的详情页「档案」里都有一行 **B 站首页**直达链接（`https://space.bilibili.com/<uid>`），联动页嘉宾卡上也各有一枚同样的按钮。萨摩不耶另有专属**特性**「一哥」（社区都这么叫他）：对上奖励首领「校猫」时伤害 +50%，靠角色数据里的 `trait.vs` 表驱动，见 DESIGN §20.2。
- **挑战**：无限塔（每日 3 次，生命继承）、融灾试炼（第 71/72 期的真实区域首领，C 到 SSS 六档威胁）、25 个成就、新手引导、伤害 / 治疗统计。

## 数据管线
`public/data/game-data.json` 与 `public/img/` 分两步生成（需要 Pillow）：
```bash
python3 tools/build_data.py --src ../qdby_chinese            # 角色、命轮、密契、造物、怪物
python3 tools/build_morimens.py --morimens ../qdby_main --chinese ../qdby_chinese   # 真实技能文本、关键词、融灾试炼
python3 tools/build_monsters.py --morimens ../qdby_main --chinese ../qdby_chinese    # 真实怪物表、出招序列、意图图标
python3 tools/build_orders.py                                                        # 原作 63 件钥令（名字/界域/效果/图标）
```
第二、三步读取《战报侦探》仓库 `main` 分支（`qdby_main`）里整理好的中文数据（`dictionary / official-terms / skills / keywords`），以及 `qdby_chinese` 的客户端怪物表 `data/morimens/maps/monsters.json`。图片已压缩为 webp 缩略图（总计约 6MB）。技能中文为 AI 辅助译文，数据来源 SKeyDB（CC BY-NC-SA 4.0），故本项目仅限非商业使用。

- 一键配装（`fillLoadout`）与主线「一键配队」共用同一套逻辑。
- **编队库里的「上阵」= 人和配装一起搬**：卡片上的战力是按这套自己的配装算的，只换人会把装备留在原地、上阵后战力对不上，所以 `loadSquad` 默认连 `lo` 一起写进主线（想只换人就传 `applyLoadout = false`）。点完会直接切到「主线队伍」页并弹提示，卡片按钮同时变成「已在主线」、状态行写「✓ 主线正在用这套」，免得点了看不出变化。

- **编辑禁区队走的是禁区那五套**：从编队库点「禁区一队 … 禁区五队」的「编队 / 配装」，保存按钮只会是禁区一~五队，不会像以前那样认不出 mode、把人和配装存进通用一队（`isRiftSquad(key)` 参与判定）。
- **编辑属性塔队只动那座塔的一套**：四座塔各有专用编队位（`t_CHAOS` / `t_CARO` / `t_AEQUOR` / `t_ULTRA`），编辑器里只有一个保存按钮；挑战页的胶囊也只列「当前队伍 / 本塔专用队」。以前四座塔都借通用一队~五队、默认还都落在「一队」，给混沌塔编一次，另外三座跟着一起变，等于四座塔共用一套。老存档里指向 a~e 的会在 `migrate` 里把本界域成员搬进 `t_*`（不合界域的不搬，留空退回当前队伍）。

- **编队里的「详情 → 换一件」只改这套的独立配装**：造物格点进去是详情，详情里的「换一件」以前走的是主线造物栏（`state.gear.relics`），所以在编队里换完「看着没变」（编队草稿没动）、主线反而被改掉了。现在编辑器会给详情弹窗传 `onSwap` 回调，替换的是 `st.lo.relics` 里的那一格（同一件造物在这套里不会重复），主线不受影响；强化 / 精炼后弹窗重开仍记得是编队上下文（`relicSwapCtx`）。主线队伍里的「换一件」行为不变。
- **换装列表里的「已编入」跟着草稿实时走**：在编辑器里给这套配装备时，「选择造物 / 选择命轮」列表上的归属标签以前只读存档，刚配进「三队」也还写着「一队」，看着像没生效。现在 `squadsForItem` 会把正在编辑的那套按草稿算，标签写成「三队·草稿」（虚线金框）；关掉编辑器（✕ / 点遮罩）或保存后草稿作废，标签回到存档里的样子。
- **可选唤醒体多了定位 / 稀有度筛选**：原先只按界域筛，同界域里要在一堆人里翻。现在三行胶囊（界域 / 定位 / 稀有度）任选，标题旁显示「筛后 / 总数」，一键「清除筛选」（属性塔锁定的界域不受影响）。

## 钥令与装备的数值平衡

- **钥令不再「属性条数越多越强」**：以前 `tools/build_orders.py` 的 `bonus_of` 把原文里命中的每条关键词都加一遍，键数 1→8 直接对应价值 5→38 分，于是描述越长越强、R 卡能比 SSR 强三倍（R「巨人的霸道」7 键 42.8 分，比全部 6 件 SSR 都高）。现在先按稀有度给**价值预算**（R 11 / SR 16 / SSR 22 分），再分配：招牌键优先、最多留 3 个键（3 键再打 94 折）、主属性拿 62% 预算。结果：SSR 20.8–22.2 / SR 14.4–16.4 / R 8.9–11.5，键数 1/2/3 的均值是 10.6 / 14.4 / 11.9 —— 稀有度单调、键数不再等于强度。
- **每件钥令有定位标签**：`tag` 由招牌键决定（锐意 / 强攻 / 锋矢 / 起手 / 狂澜 / 慈悲 / 守势 / 汲取…），钥令页与选择弹窗里跟在名字后面，一眼看出这件是加伤害、给起手资源还是保命。63 件里 9 类，最多的一类 12 件。
- **命轮加了「器纹」**：149 件命轮以前只有 8 种（= 8 条主词条），同主词条的两件除了名字完全一样。现在按 `hash(id)` 再挂一条**固定**小加成（起手共鸣 / 起手钥焰 / 吸血 / 濒死存活 / 金币 / 首击增伤 / 增伤 / 治疗），不吃等级与精炼，所以不会随强化滚雪球；`wheelText` 里写成「伤害提升 +23.5% · 器纹 治疗 +3%」。
- **造物加了「特质」**：同理，310 件造物只有 10 个主题，同主题同稀有度的一模一样。现在按 `hash(id + ':r')` 再挂一条固定小加成，和主题属性叠加（`relicBonus`）。
- **主词条 base 调平**：共鸣 / 钥焰回复从 22 降到 16（22% 一档等于用一条主词条换到近 +10% 输出，比增伤 8%、攻击 8% 都值），暴击率 6→8、暴击伤害 14→16，让 8 条主词条按「队伍缺什么」选，而不是「谁数字最大」。
- 审计口径：价值权重表在 `build_orders.py` 的 `VALUE_W`，是**锚在原数据量级**上的折算单位（主键预算 ÷ 权重 ≈ 原来最强那批的数值），不是纯理论收益。改权重等于改全局强度，动之前先跑 `tools/balance-audit.mjs`。

## 存档可靠性

- 存档同时写 localStorage（主）和 IndexedDB（镜像，5 秒内最多落一次）；每次存档 `state.rev` +1，启动时两份取 rev 大的，所以只丢了其中一份（配额满 / 内置浏览器只清 localStorage）也能恢复，并提示「已从备份恢复」。
- 启动时申请「持久存储」（`navigator.storage.persist()`），降低被浏览器清理的概率。
- localStorage 写入失败（空间满 / 无痕）会弹一次警告，建议导出存档。读出来损坏的存档会先备份成 `morimens-idle-save-v1-corrupt`，不会被下一次存档悄悄覆盖。
- 多窗口 / 标签页：回到前台或收到别的窗口的存档事件时，如果磁盘上的 rev 更大就同步过来，旧窗口不会再把新进度覆盖回去。
- 「重置所有进度」之前会被关闭页面时的自动存档写回去（实际重置不了），现在重置期间禁止存档，并连 IndexedDB 一起清。
- 浏览器清站点数据 / 换域名访问（`z769018860.github.io`、`morimens.qingdengbuyi.top` 等是不同来源，存档互不相通）仍然会丢，请定期在设置里导出存档。

## 后台挂机（最小化 / 熄屏 / 切标签页）

- 页面进后台（`document.hidden`）时战斗动画会停，但**回来会补收益**：按「切走的时刻」跑一遍和离线结算同一套公式（`offlineReport(state, data, now, since)`），最长 8 小时，超过 60 秒才算。回来时用一条 toast 报账（金币 / 唤醒券 / 银芯 / 装备几件），不弹结算框——弹框只在重新进游戏时用。
- 以前这条路径是坏的，两个原因：① 后台每 15 秒还会存档一次，`lastSeen` 被刷成「刚刚」，回来时 `away < 60000` 直接开打，一分钱都不结算；② 切到后台时 `bv.stop()` 把战斗链（`setTimeout` 串联）停掉，看起来就是「最小化就不挂机了」。现在用 `app.bgSince` 单独记「切走的时刻」，并让 `save()` 在 `document.hidden` 时不推进 `lastSeen`；直接关掉页面时 `lastSeen` 停在切走那一刻，下次启动照样按它结算。
- 为什么不让战斗在后台真的继续跑：浏览器对隐藏页的定时器会节流（Chrome 隐藏 5 分钟后约 1 次/分钟），真打只会更慢；按公式结算既快又和「关掉页面再进」的结果一致。

## 云端存档（整份进度上云）

- 个人中心的「云端档案」只同步积分 / 解锁 / 最高分和各游戏的进度**摘要**，挂机前夜的真实存档一直只在本机，换设备就是从头开始。现在登录本站账号后，挂机前夜的**整份存档**会自动同步到云端（后端 `/save/idle`，`core/cloud.js`）。
- 规则（乐观锁）：云端每次写入 ver+1，本机记着「上次同步时云端的 ver 和本机的 rev」。云端没变、本机改了 → 推上去；云端变了、本机没改 → 直接拉下来；两边都改过，或新设备上两边都有进度 → 弹窗让你选「用云端 / 用本机 / 先不处理」，**不会悄悄覆盖任何一边**。新设备上本机还是新档时直接拉云端。
- 时机：进游戏 2.5 秒后、回到前台、本机改动后 25 秒内、离开页面（keepalive）。拉下来的存档会把 `lastSeen` 重置为现在，这段时间已在另一台设备上结算过，不重复发离线收益。
- **离线收益按「云端进度」结算**：同步下来的是云端的存档（关卡、最高关、挂机关卡都在里面），所以离线金币 / 券 / 银芯 / 掉落一律按云端那份算，不是按本机原来的挂机关卡。为此启动流程会先等云存档真正落地再结算（`waitCloudIdle`，最多 15 秒；冲突框点「用云端的」也是异步的，以前会先按本机进度弹一次结算、云端档到了也不改算）。已经在弹的旧结算会被作废并按新档重算（`settleToken` + `app.cancelSettle`），不会出现「按第 8 关结算完，云端其实是第 30 关」。
- 手机切回前台时，如果离开超过 1 分钟，先同步云端再结算（同样 `keepCloudSeen`，不重复发这段时间的收益）；离开不到 1 分钟就直接继续打，不打断战斗。
- 设置页有「云端存档」卡片：状态、自动同步开关、「立即同步」、「用云端存档覆盖本机」。
- 换手机的做法：手机上先在首页登录**同一个账号**，再打开挂机前夜即可。存档上限 480KB（现在约 50KB）。
- **存档装不下时的两级压缩**（`core/cloud.js` 的 `packSave` / `unpackSave`）：装备库存是没有上限的，玩到后期动辄几千件、一件 JSON 要 60~70 字节，一份存档能涨到几百 KB，直接撞上服务端 480KB 的上限——以前这种情况会一直报 `too_large`、每次重试都失败，云端的存档就冻结在旧版本，换设备拉下来的是几个月前的进度（签到、编队库、无限塔 / 融灾禁区、联动人气、唤醒体养成全都「不继承」，其实就是没传上去）。现在：明文超过 400KB 先把 `gear.items` 压成数组（`{"__pack":1}`，仍是合法 JSON，老服务端也认，体积约 1/3），还不够再 gzip + base64（`gz1:` 前缀，25 万字节压到 30KB 左右）。客户端两种格式都认，服务端只需要把 `gz1:` 当字符串收（`edge-functions` 里 `idleDoc()` 负责解，管理员查看与榜单补阵容都走它）。
- 同步失败会自己重试（15 秒起、指数退避、封顶 5 分钟），设置页的状态行会直接写失败原因（`too_large` 时带上当前存档体积），不再只是「稍后会自动重试」却一直不动。
- 后端只在 EdgeOne 版（`edge-functions/api/[[default]].js`，接口版本 v7）实现；`server/worker.js`、`server/node.js` 没有这组接口。

### 专属技能（满超限 / 满最终法则）

每位唤醒体（含 9 位彩蛋角色，共 71 位）各有两个**手写、不重名、效果组合互不相同**的专属技能（`src/core/extra.js` 的 `SKILLS` / `EXTRA_NAMES`）。设计口径是一人一对：

- **超限技 = 节奏位**：把他自己 kit 里最顺手的那件事，做成「每行动 N 次免费追加一次」的循环（盾系补盾、毒系续毒、能量系充能、输出位补一段伤害）。
- **终焉技 = 收束位**：把自家 kit 造出来的战场状态兑换成一记爆发——毒、流血、反击层、屏障、护盾、能量、血线，各自换成伤害 / 治疗 / 护盾。所以同一个人打久了会形成「先铺状态、再收账」的节奏，而不是所有人共用一张模板。
- **节奏是第三个性别维度**：`every` 逐位不同（2 = 快节奏单次轻，5 = 慢重击单次重），71 位里有 20 位不在默认的 3 / 4 拍上。
- 追加的技能不占回合、不进冷却；战斗日志里显示为「超限技 / 终焉技」；角色详情页底部「专属技能」列出名字、主题（如「毒 · 毒层转治疗」）、节奏和本作效果。

为此在 `core/battle.js` 的 `run` 里补了 6 个「状态兑换」型机制（连同之前的 20 个，专属技能一共 26 种机制词汇）：

| 新机制 | 燃料 → 产出 | 代表 |
|---|---|---|
| 反击爆发 `counterBurst` | 全队反击层数 → 全体伤害（保底 2 层） | 凯刻斯、菲茵特、诺缔拉、潘狄娅、旺达、温柯尔 |
| 屏障化疗 `barrierHeal` | 屏障层数 → 治疗（每层 % 最大生命） | 艾瑞卡、诞妄·墨菲、萨摩不耶、路过的耄耋、温柯尔 |
| 能量超载 `gaugeBurn` | 共鸣 / 超共鸣能量 → 伤害（保底 60 点） | 卡茜亚、奥尔拉、汀克特、立誓0氪 |
| 以毒养身 `poisonHeal` | 敌人身上的毒层 → 全队治疗 | 卡伦、法洛思、弥利亚姆、徐、薇薇安、泰旖丝 |
| 毒甲 `poisonShield` | 敌人身上的毒层 → 全队护盾 | 阿格里帕（其余毒系走毒爆 / 毒疗 / 扩散） |
| 流血扩散 `dotSpread` | 最重的一份流血 → 传染全体 | 血链·希洛、鼠王 |

**平衡怎么做的**：`tools/extra-bench.mjs` 逐位量「带上这对专属技能比不带多赢多少」（同一批关卡、同一批种子、陪跑位一律不带专属技能，只切换被测那一位），`tools/extra-tune.mjs` 按这个边际增益反过来校准 `extra.js` 里的 `TUNE` 系数（只缩放力度，不动结构 / 层数 / 回合数，并且有上限：伤害倍率 ≤ 400%、比例扣血 ≤ 14%、增益 ≤ 60%，避免「一发清场」）。校准前后（lv60 ★10、44–74 关 × 7 种子）：

| | 边际增益均值 | 标准差 | 最差 ~ 最好 |
|---|---|---|---|
| 重做前（18 个模板家族） | 3.3 | 4.4 | −8.2 ~ +14.2 |
| 重做后（逐位设计 + 校准） | 6.1 | 1.9 | +1.7 ~ +10.2 |

也就是说：没有哪位的专属技能是白练的（最低也有 +1.7 个百分点的胜率），也没有哪位靠它一家独大。彩蛋角色的技能名只按昵称里的意象原创，和本人设定无关。

### 唤醒体羁绊与跨域共鸣（M20）

以前「同界域 3 人 +8% / 4 人 +15%」是唯一的组队加成，于是四同域是唯一正解，混编队（不同界域搭着上）不但凑不出加成，还白白丢掉那 8%，基本没人玩。M20 补了三层：**唤醒体羁绊** + **跨域共鸣**，两者都写在 `core/bonds.js` / `core/game.js`，全部是**全队被动**（不看站位、人倒了也还在，和造物羁绊同一口径）。

羁绊一共 **38 条、9 类**：

| 类别 | 条数 | 怎么凑 | 例子 |
|---|---|---|---|
| 初始之约 | 1 | 开局四人（奥吉尔 / 萝坦 / 朵尔 / 拉蒙娜）2 / 3 / 4 人 | 4 人：生命 +13% 攻击 +13% 增伤 +6% |
| 同源双相 | 6 | 本体 + 异相同时在队（六对 Genesis 各自一位） | 萝坦 + 蚀灭·萝坦：攻击 +12% 增伤 +8% |
| 同域同心 | 4 | 同界域点名的三个人 | 阿格里帕 / 艾继丝 / 泰旖丝：生命 +12% 防御 +10% 治疗 +8% |
| 职业阵型 | 3 | 同类型 3 人 → 4 人再上一档，**不看界域** | 三名突击：攻击 +8% 暴伤 +18%；四名再 +6% 攻击、+12% 暴伤、+6% 增伤 |
| 联名主播 | 4 | 主播 × 主播（同界域配对 / 血肉三人） | 萨摩不耶 + 魔龙_D：攻击 +10% 首击 +20% |
| 主播 × 唤醒体 | 4 | 1 位本界域主播 + 2 名本界域唤醒体，+3 名再上一档 | 混沌连麦：增伤 +8% 起始钥焰 +12 |
| **本命羁绊** | **14** | 主播 + 他在《唤醒体幸存者》里带的那位官方唤醒体 | 萨摩不耶 + 血链·希洛「血色节拍」：攻击 +12% 吸血 +3%；萨摩不耶 + 茉夏「雪原利爪」：暴击率 +6% 暴伤 +20% |
| **档案派系** | **1** | 原作档案 `特性` 同标签，2 / 3 / 4 人分档 | 神国余晖（利莫里亚 5 人）：4 人增伤 +22% 共鸣 +20% 护盾 +15% 生命 +14% |
| 跨界同行 | 1 | 队伍里 3 / 4 个不同界域 | 四域：生命 +14% 攻击 +14% 增伤 +10% 暴击率 +5% 起始共鸣 +15 |

**本命羁绊**来自 `data/survivors-extra.json` 里每位主播的 `bonds` 表（幸存者那款游戏里「主播 × 官方唤醒体」的专属联动），13 条按 `cid → pid → slug` 对到本作：萨摩不耶 × 血链·希洛、梦依流苏 × 凯蒂古拉 / 波吕克斯、爱丽丝 × 潘狄娅 / 旺达、鼠王 × 詹金、魔龙_D × 艾瑞卡、立誓0氪 × 血链·希洛、夏茉琳 × 索蕾尔、朝星 × 菲茵特、路过的耄耋 × 奥吉尔、白云出岫 × 塔薇 / 詹金。幸存者里那套数值（冷却、拾取范围、召唤物）本作没有对应字段，换算成攻击 / 生命 / 防御 / 暴击 / 增伤 / 吸血 / 共鸣 / 钥焰。血链·希洛与詹金各被两位主播认领，所以「本命」认的是人不是那位唤醒体。另外玩家点名补了一条 **萨摩不耶 × 茉夏「雪原利爪」**（暴击率 +6% 暴伤 +20%）——幸存者表里没有这对组合，是照茉夏「突破·眩晕重击」的路子给的。

**档案派系**来自 `data/dictionary.json` 的 `traits`（维基档案的 `|特性=` 字段）：全 62 位唤醒体里只有两枚标签，「利莫里亚」5 人（法洛思 / 戈利亚 / 弥利亚姆 / 诞妄·墨菲 / 图鲁）与「主宰」1 人（茉夏）。主宰只有一位成员、凑不成组，等官方补人；所以这一组现在只有神国。数值照官方的节奏——原作灵塑写的是「队伍中存在 1 / 2 / 3 名其它利莫里亚唤醒体时，触腕伤害 +6% / 15% / 30%」，本作没有触腕伤害，换算成增伤（主）+ 共鸣 / 护盾 / 生命（次），并且**每一档都带一点生命**：战力只认生命 / 攻击 / 防御，纯增伤 / 共鸣的羁绊在战力上看不出来，会让人以为没生效。往后加派系照着表里追加一条即可（`members` 写 slug、`tiers` 按人数分档）。

**规则型羁绊**（职业阵型 / 主播×唤醒体 / 跨界同行）按人数分档，取「够得着的最高档」；点名型羁绊看队里凑了几个。「主播 × 唤醒体」的计数固定为 **1 位主播 + 本界域唤醒体数**——带两个同界域主播也只算 1 位，免得双主播把档位虚高到 4。

**跨域共鸣**：队伍凑齐 **3 个不同界域 +6%、4 个 +10%** 生命 / 攻击（`MIXED_SYNERGY`）。它和同域加成**互斥**——能凑出 3 同域就吃同域那份，否则看界域散不散。四个人的队伍里这两件事本来就凑不到一起（3 同域 + 1 别域 = 只有 2 个界域），所以不冲突，只是给混编队补上「以前什么都没有」的那一档。

界面上：队伍页（主线）有「唤醒体羁绊」一栏，激活的是金边胶囊 + 加成读数，下面跟最多 4 条「差几个人就能凑」的提示（**按差多少排序，差 1 人的排最前**——表长到 38 条以后，按声明顺序排只会一直显示那几条永远凑不出来的），再往下折着 **全部 38 条一览**（按类别分组，每条写清成员、各档数值与做法）；编队编辑器里有一行紧凑版的羁绊条（边选人边看），编队卡标题写着「羁绊 N」，角色详情页多一行「羁绊」标签（已激活的金边）。战力（`power`）与所有挑战（塔 / 周 Boss / 融灾 / 竞技场快照）都走 `teamDefs`，所以羁绊自动算进战力与实战。

**平衡**：`teamDefs` 里羁绊加成先进 `allyDef` 的装备加成池，再乘同域 / 跨域倍率，所以战力与战斗完全同源。校准用「改动前 / 改动后两棵树跑同一批阵容」的办法——同一套阵容的**稳定通关上限**保持不变（各阵容 39→39、56→55、64→65、73→73、98→98，战力 +10~16%），也就是说这波增强被同版本的怪物加压抵掉了，玩家不会因为羁绊白拿关卡。

本命羁绊与档案派系是后补的两类，单独量过（Lv60，把这两类临时摘掉再跑同一批阵容）：两个本命对 **+5.4%**、本命 + 混编 **+3.5%**、神国四人 **+3.1%**、神国三人 **+1.7%**，纯官方向与旧的主播×主播组合 **0%**——增幅都落在一位数，不需要再给怪物加压。

### 后期怪物加压

**70 关**之前怪物数值不变；70 关之后每 10 关再叠一层复利：**生命 ×1.115、攻击 ×1.065、防御 +4.5%**（`core/enemies.js` 的 `lateBoost`，对主线、塔、融灾等所有用 `makeEnemy` 的模式生效）。例如 100 关：生命 ×1.41、攻击 ×1.24、防御 ×1.14；130 关：生命 ×1.93、攻击 ×1.46、防御 ×1.27；200 关：生命 ×4.6、攻击 ×2.4、防御 ×1.59。

这版比上一版（80 关起、1.10 / 1.06 / +4%）更陡，原因是 M20 的**唤醒体羁绊 + 跨域共鸣**把满编队的生命 / 攻击抬了 10~16%：不加压就等于白送十几关。校准方式是拿「改动前 / 改动后」两棵代码树各跑一遍同一批阵容的稳定通关上限（`node tools/...`，见下方「羁绊平衡」），要求同一套阵容的**通关上限不涨**——战力涨了，但不多给关卡。

### 周 Boss 三层（M20）

周 Boss 从「一层拼伤害」扩成 **三层**：同一个 Boss，第 2 / 3 层按更高关卡模板出数值（+8 / +16 关的 Boss 档），再乘攻击 ×1.35 / ×1.7、防御 ×1.25 / ×1.5，并挂上「狂暴 / 坚壳」词缀（名字上就能看出来）。

| 层 | 解锁条件 | Boss | 同一档里程碑奖励 |
|---|---|---|---|
| 第 1 层 | 无（老存档的进度都在这层） | 基准 | ×1 |
| 第 2 层 | 第 1 层**本期**累计伤害 ≥ 12 万 | 攻击 ×1.35 · 防御 ×1.25 · 狂暴（攻击再 ×1.2） | ×1.6 |
| 第 3 层 | 第 2 层**本期**累计伤害 ≥ 70 万 | 攻击 ×1.7 · 防御 ×1.5 · 坚壳（防御再 ×1.3） | ×2.4 |

三层**各自记一份累计伤害、单次最高与已领档位**（`state.weekly.tiers[1..3]`），每日 3 次挑战三层共用、自选打哪层；换周（ISO 周）三层一起清零。老存档里顶层的 `damage / best / runs / claimed` 在 `weeklyState` 里一次性迁进第 1 层，迁完就把老字段删掉，避免两处各算一遍。界面上方是三层胶囊（锁住的显示 🔒 并在 title 里写解锁条件），下面是这一层的进度条与里程碑（奖励数字已经乘上该层倍率）。

### 大招策略（战斗策略 → 大招）

队伍页「战斗策略」下新增一行**大招**，三选一（存在 `state.strategy.ult`，换预设不会丢）：

| 策略 | 行为 |
|---|---|
| **优先开大**（默认） | 大招（共鸣 / 超共鸣）一攒满就放，排在防御、技能之前（唤醒之后）。唯一例外：这一发**完全白给**（纯治疗 / 护盾型大招、全队满血、下一轮也没人要挨打、连充能收益都没有，分值为 0）时先做别的，下一次行动必定开 |
| **攒大招一起开** | 等全队活着的人都攒满再一起放，打出爆发窗口；某人等了 3 次行动还没等齐、或自己血量低于 30% 就不等了 |
| **按顺序开大** | 在下面用 ↑ ↓ 把队里 4 位排个先后：排在自己前面、而且已经攒满的人还没开（说明它这轮还没轮到），后面的就先等——最多等 2 次行动，免得被控死的人把全队拖住。适合「增益 / 充能类大招先落地，再让输出位开」的打法。顺序存在 ，换人 / 换队会自动增删成当前这 4 位 |

「手动开大」已下线：战斗是预先模拟好的整段事件流，点一次就要整段重算，观战节奏会被打断，也容易点空（指令没赶上那一回合）。改成排顺序后，战斗仍然是纯自动、可离线、可复现的，但玩家对「谁先开」仍然有控制权。老存档里的 `ult: "manual"` 会在 `migrate` 里回到「优先开大」。

### 启动顺序：先对云存档，再结算离线收益

进游戏时先把云存档对一遍（最多等 8 秒），拉到的存档**保留它自己的 lastSeen**，再按最终存档结算离线收益。冲突框弹出时先等玩家选完再结算；离线收益弹窗还没领时，不会被后台同步换掉存档。

这条顺序在手机端原来有个洞：门户是**页面加载之后**才把账号 token 交过来的，`Cloud.account()` 那一刻还是空，于是「云端有没有更新」整步被跳过，挂机收益先弹出来让玩家领了，等账号到位再同步就成了冲突——选「用云端的」就把刚领的那笔盖掉了。现在：

- **先等账号**（最多 4 秒）再决定要不要同步，不让 `account()` 为空把整步跳过去。
- **领完立刻推一次**（`cloudRun('auto')`），不留「本机多一笔、云端还没有」的分叉等着下次同步去撞。
- **兜底**：真发生了「已经领了、云端那份才落地」（手机网络慢的常见路径），`applyCloudSave` 会把那笔收益原样补回到云端存档上，并 toast 告知；同时把 `lastSeen` 推到现在，不会重复发第二遍。
- 冲突框里如果本机有这笔还没上传的收益，会**明写出来**（金币 +多少、券 +多少），并且说明选「用云端的」会自动补回。

## 90 关之后：域规与放缓的曲线

主线 90 关之前一切照旧。90 关之后：

- **曲线放缓**：怪物成长从每关 ×1.085 降到 ×1.065，80 关起的额外加压在 90 关之后减半（`core/enemies.js` 的 `enemyScaleMain` / `lateBoostMain`）。无限塔、属性塔、试炼、禁区、周 Boss 沿用老曲线。
- **域规**：每一章（10 关）换一条规则，首领关与 140 关之后每章叠两条（`domainRules`）：屏障怪 / 反震 / 治疗压制 / 重甲 / 封印。规则写在战斗页与「下一关」面板里，附对策提示——自动战斗没法临场应对，所以要提前换阵容。
- **持续伤害补偿**：毒 / 流血 / 反击伤害在 90 关后按怪物成长补一个倍率（`lateDotBoost`），否则它们的层数上限追不上怪物生命。

## 毒 / 流血 / 反击也吃防御

- 以前这几类伤害直接调 `applyDamage`，等于**完全无视防御**：重甲（防御 ×2）对它们毫无抗性，前排堆防御也不减少这些伤害，域规提示里还专门写着「毒 / 流血 / 反击无视防御」。
- 现在统一过一遍防御曲线（`battle.js` 的 `guarded()`），但只吃**一半**减伤（`softCut` = `1 - (1 - 防御减伤) / 2`）：全额减的话，高防怪面前靠持续 / 反击吃饭的阵容直接掉档；半量既让防御生效，又保住它们「对付重甲有半条路」的定位。覆盖范围：毒 / 流血跳伤、中毒引爆、流血引爆、反击（含反震 / 反射 / 反击爆发）、延迟爆发、护盾转伤害、超载。比例扣血（`pctHp`）照旧绕开防御——那是重甲的正解。
- 基础数值原本是按「无视防御」调的，吃上半量防御后中前期约掉 10~20%，所以给这类伤害补了 `SOFT_KEEP = 1.2`。体检（`tools/ai-bench.mjs`，lv60/star10，20~52 关 ×4 种子）：全员胜率 81.3% → 80.3%，守护 71.0% → 67.3%（每档 20 场的采样粒度是 5%）。
- AI 估价（`scoreEffect` / `debuffWorth`）用同一个 `softCut` 折算毒与流血的收益，免得把群毒估高一截、把它排在不该有的顺位上。

## 疾驰欢愉的大运（`core/luckrun.js` + `ui/luck.js`）

类杀戮尖塔的三层挑战，入口在「挑战 → 疾驰欢愉的大运」。

- **一局 = 3 层 × 12 个节点**：每层 10 场战斗（7 普通 + 2 精英 + 1 首领）+ 1 个事件 + 1 个商店。节点顺序固定（`NODE_PLAN`），内容按 run seed 随。
- **血量跨节点继承**：打完一场按 `res.allies` 的比例写回 `run.hp`，下一场用 `hpNow` 注入；倒下的队员（比例归零）下一场不上。三层之间与首领战后各回 15%，不然第三层只能拖着残血硬顶。
- **每场战斗后三选一**：战斗增益（可叠层）/ 造物（整局唯一，改玩法）/ 本队角色的专属强化。有「赌徒之骰」时是四选一。重掷每局 1 次（天赋与造物能加）。
- **造物**共 28 件，效果分三种：`mod` 直接叠到单位 def 上（攻 / 血 / 防 / 暴击 / 增伤 / 吸血 / 濒死存活 / 开局护盾）；run 级的数值字段（`after` 战后回血、`glow` 每战余晖、`score` 结算加成、`discount` 商店折扣、`event` 事件收益、`extra` 多一个选项、`reroll` 重掷）统一由 `relicSum(run, key)` 读，所以新造物只要在数据里写一个字段，不用到结算里加分支；还有三个改节奏的：`revive` 每层一次复活、`eliteScore` 精英 / 首领战分数、`act` 每层额外回血。
- **专属强化**按角色的定位生成，每人两条：突击吃攻击与暴击、守护吃身板与护盾、合唱吃治疗与增伤。名字是「角色名 · 强化名」，70 多位角色不用逐条手写也不会撞名；效果只加在那一位身上（`modsOf(s, run, slug)` 按 slug 过滤）。
- **事件 16 个、商店 1 个货架 3~5 件**：事件选项的代价与收益都写在明面上（花余晖 / 掉血换造物 / 敲钟换分数），商店用「余晖」结算——**不碰玩家的金币与银芯**，这是 run 内货币。事件收益键共 9 种：`glow / score / heal / maxhp（生命上限）/ buff / relic / gamble / reroll（重掷次数）/ up（白给专属强化）`。
- **五档难度**（闲庭 / 疾驰 / 大运 / 逆天 / 无疆）：`scale` 乘敌人血与攻、`mult` 乘结算分数、`lv` 是推荐平均等级（主页会拿当前队伍平均等级对照，差 8 级以内高亮）。
- **分数 → 等级 → 奖励**：单局分数累积到 `luck.pts`，等级表 **60 级**（31 级起 1.07 倍曲线，天赋点每 4 级 1 点），每级一份奖励 + 1 点天赋点，每 5 级两张唤醒券、每 10 级一张免费回溯券。门槛 1–15 级沿用 1.3 倍曲线（第 15 级 6300 分），16 级往后改 1.06 倍（第 30 级 15098 分，到顶累计约 18 万分 ≈ 逆天/无疆二十来趟）。主页默认只显示最近几级，可展开全部。
- **天赋** 12 项（上限合计 38 点，够点满一半多）：生命 / 攻击 / 防御 / 暴击率 / 暴击伤害 / 增伤 / 护盾加成 / 起始余晖 / 商店折扣 / 战后回血 / 结算加成 / 重掷次数。点数靠等级奖励，永久生效。
- **专属成就** 12 条（首次过关、三层通关、逆天通关、单局 1500/3500/6000 分、8 / 12 件造物、通关时全队 70% 血以上、单局 300 / 500 余晖、累计通关 5 次）。

所有逻辑都是 `(state, data, run)` 的纯函数，不碰 DOM、不读时钟，所以能在 Node 里整局跑完做体检（见 `tests/core.test.mjs` 的大运用例：节点推进、奖励三选一、血量继承、专属强化、等级 / 天赋 / 成就、难度梯度、30 级阶梯、内容池字段校验、生命上限与不灭余烬）。

## 红流树海（`core/treerun.js` + `ui/tree.js`）

挑战页里的第二个肉鸽：沿用大运「3 层 × 10 场战斗」的骨架，玩法换成集成战略（萨米肉鸽 / 红流树海）的路子。入口在「挑战 → 红流树海」。**这个模式里角色练度与装备都和账号无关**——练度锁死 50 级白板，装备要在局内自己赚。

- **开局分队**（`TREE_SQUADS`，6 支）：出发前先挑一支，整趟的规矩就不一样——**前锋**（可上 5 人，全队生命 -12%）/ **后勤**（黑露 +30、招募 -20%、余晖 +12，生命 -3%）/ **猎手**（开局 2 件装备，猎场每次掉 2 件）/ **祭祀**（开局带 1 条祝福，祭坛代价减半）/ **拾荒**（每胜 +10 余晖，结算 +12%）/ **漂泊**（仓库 10 人、重掷 +1、招募 -10%、白得 1 件装备）。分队只定这一趟，下一趟能换；选过的分队会记住。
- **岔路地图**：每层 10 步，前 9 步每步给**两条岔路**二选一（⚔ 战斗 / ✦ 紧急作战 / 🐗 猎场 / ❖ 奇遇 / ⌂ 黑市 / ♨ 休整 / ✧ 古树试炼 / 🎁 宝箱 / ⛲ 回声之泉 / 🕯 古树祭坛），第 10 步固定首领。猎场是加强版精英战，必掉一件装备；宝箱免费三选一装备；泉水救回倒下者或大回血；祭坛用 10% 生命换一条永久祝福（8 种，祭祀分队只扣 5%）。快走完一层还没遇到奇遇 / 黑市时权重自动拉满（保底）。
- **黑露募队进仓库**：开局 100 黑露从**已拥有**的角色里挑人（史诗 / 创生 26、精良 18、稀有 12、普通 8），募到的进**仓库**（最多 8 人，开局先上前 4 人）。黑市与奇遇能继续招人进仓。
- **仓库面板（战斗前编队）**：任何时刻可开——从仓库挑人上场（人数上限看分队，倒下的人上不了场，要用泉水 / 事件救回来）、装 / 卸装备。装备分三类：**环**（个人，每人 1 个）、**契**（全队，常规 3，天赋可加到 5）、**令**（全队，同上），共 28 件，数值刻意比账号装备小。
- **装备与练度都和账号无关**：影子练度（`ovr`）锁 50 级 / 0 叠 / 0 超限 / 0 法则，`allyDef` 的 `bare` 模式把命轮 / 密契 / 造物 / 钥令 / 同调率全部屏蔽——测试专门验证「满配账号进树海，面板和空号一模一样」。装备只能在黑市买、宝箱开、猎场 / 首领掉、奇遇换、战后三选一里拿。
- **古树的馈赠**（三选一）：点亮下一档强化 / 树海造物二选一 / 回血 30% + 25 余晖。强化三档递进：**高枝**（159 级 + 满叠位）→ **超限**（od 99）→ **终焉法则**（法则 10）。树海造物 12 件（整局唯一）。
- **天赋树 + 等级奖励（局外成长）**：每局结束按得分给树海经验（pts）与天赋点（通关另加）。天赋树四支——**生长**（开局黑露 / 招募折扣 / 全队生命 / 白得造物）、**低语**（初始余晖 / 商店折扣 / 战后回血 / 结算分数）、**根须**（攻击 / 防御 / 暴击 / 增伤）前三支加数值；第四支 **枝杈** 专改**玩法规则**：每步三选一、契令槽各 +1、开局重掷 +1、**全队第一次倒下不算结束**（以 35% 生命原地站起）。共 16 项 45 级，线性前置。等级 1~25 级：金币 / 银芯 / 唤醒券 / 天赋点，每 10 级一张界域唤醒券，5 / 15 / 25 级各一张通用券，25 级给直升券。
- **账号级奖励**：**唤醒券按界域分**（混沌 / 血肉 / 深海 / 超维，`vouchers.awaken` 是四键对象），只能唤醒对应界域的角色；**通用唤醒券**（`vouchers.univ`）任意界域都能换，用的时候**先扣对应界域的券、界域券空了才动它**——把灵活的那张留在手上。各难度首通、成就、黑市、等级奖励都会出，通用券只从 5 / 15 / 25 级、深根 / 红流之心黑市、「六路同行」成就里出。**「红流之心」首通送直升券**（叠位 99 / 等级 159 / 超限 99）。老存档的单个数字唤醒券迁移为血肉券。
- **五档难度**（微光 / 低语 / 树影 / 深根 / 红流之心）：`off` 把敌人曲线挪到主线第 N 关（第 91 关起域规自然出现），`scale` 再乘一层。定档口径（0 天赋、自动装备的模拟玩家，14 局 / 档）：100% / 100% / 79% / 43% / 21%——真实玩家有天赋与手动编队，还会更松一档。体检工具：`node tools/tree-audit.mjs [局数] [分队 id]`（不指定分队时会额外跑一轮六支分队横评，树影难度）。
- **云端同步**：整个模式的进度（进行中的局、分队、仓库、局内装备、天赋树、等级经验、券）都在 `state.tree` 与 `state.vouchers` 里，随整份存档走云同步——换设备登录同一账号接着打。
- **行囊（0.16.0，跨局仓库）**：每趟结算可以**带一件局内道具**回去（输了也能带，候选按品质排序最多列 6 件），存进行囊（`state.tree.stash`，上限 8 件，不要的随时丢）；下一趟出发后在仓库面板挑一件带上——**每趟限一件、取用不消耗**（装备给同款新件、造物直接进造物栏）。行囊是账号自己的收藏，越攒越顺手，但不会让某一趟变无脑——一趟仍只能带一件。
- **结算**：分数独立记录（`state.tree.best`）；成就 19 条，奖励含界域唤醒券 / 通用唤醒券 / 直升券 / 天赋点。「黑流树海」已于 0.16.0 全局更名为**红流树海**（玩法不变）；券匣（唤醒券 / 直升券）只在树海内使用。

所有逻辑同样是 `(state, data, run)` 纯函数；`tests/core.test.mjs` 覆盖：募队预算校验、影子练度与账号**装备**隔离、仓库编队与装备装卸、装备上限、天赋树前置与扣点、等级奖励领取、分界域唤醒券的校验与迁移、事件收益、结算与首通券、云存档序列化往返（迁移后接着打）、六支分队的开局规矩（人数 / 预算 / 仓库 / 装备 / 祝福）、枝杈天赋改规则（三岔路 / 契令槽 / 留手免受一次团灭）、通用唤醒券的「先扣专用券」顺序、行囊（带走一件 / 一趟限一件 / 取用不消耗 / 满了拒绝 / 丢掉）。

## 逆潮守关（`core/denrun.js` + `ui/den.js`，0.16.0）

挑战页里的第三个模式，这一次**你站在怪物这一边**：每一关来一支「玩家阵容」（四位唤醒体 + 等级 / 叠位 + 这一关的战术规则），你要在**算力**预算里从图鉴的 537 只怪里挑怪、给每只怪定成长档，在 20 回合内把他们全部打光才算守住。

- **100 关 · 10 章**：每章一种玩家打法——雾港巡礼的标准四人队、沉没钟楼的双坦双奶（最考验输出）、猩红温室的三突击反震队、倒悬教堂的压疗+暴击、终末列车的重甲+反震……玩家等级 50 → 159、叠位 0 → 99，数值**归一化到固定曲线**（第 1 关 4200 血 / 1020 攻，第 100 关 ×6.3）：抽到谁只影响「用什么机制打你」，不影响这一关有多难。规则分布在一关 / 三关 / 五关 / 七关 / 章末，第 9、10 章开始叠两条。
- **算力编队**：普通怪 3 点、精英 5.5、首领 9，成长档 幼体 ×1 / 成体 ×1.55 / 巨体 ×2.35，预算 10 → 15（一路只涨不回落）。出招表的输出效率会把出招凶的怪攻击压低、辅助怪的抬高——群体技按**四个目标**折算、毒 / 流血与**反击**也按真实覆盖面折进定价，所以**同算力买到的每回合期望输出大致相等，差别留在机制上**，不会出现「抽到群体怪就赢」（第一版体检里一只普通群体怪三回合团灭玩家，就是这个没折算）。
- **不让一只大怪通吃**：同种只能上一只；只带一两只时玩家「收拢阵型」——防御大增、全体集火、孤零零的怪还会被打折血。四打一在数学上就打不赢，体检确认 100 关**单怪阵容 0 通过**。
- **八条守关特性**（壁垒 / 棘刺 / 蚀毒 / 汲取 / 破甲 / 狂血 / 庇护 / 噤声）各自被一种玩家打法克制（壁垒怕多段与毒、汲取怕爆发秒杀、噤声怕平 A……），玩家的战术规则（反震 / 压疗 / 重甲 / 暴击）反过来又克制一部分怪——每一关的最优解都不一样，抄不了上一关的阵容。
- **星级与奖励**：守住 1 星，剩 55% 血 2 星，剩 75% 且 12 回合内解决 3 星；首通给金币 / 银芯 / 唤醒券（章末更多），每章 30 星领一次全章大奖。进度在 `state.den`，随云存档走。
- **定档口径**（随机搜索 24 套配队取最好的那套）：**73/100 通过、均星 1.58、单怪 0/100**，分章通过率 8/8/5/10/9/8/10/6/5/4——前两章教学，第 3、8~10 章是硬仗。体检工具：`node tools/den-audit.mjs [尝试数] [--detail] [--solo]`（`--solo` 单独验证单怪阵容）。

## 毒 / 流血 / 反击吃增伤与易伤

「已经算好的固定伤害」这条捷径原来连增伤（`amp`）和易伤（`vuln`）一起绕开了：给毒队配个增伤拐，增益挂上去了，毒每跳的数字纹丝不动；易伤挂在怪身上，毒也不多吃。同样受影响的还有延迟爆发、护盾转伤害、超载、反击爆发。

现在 `guarded(出手方, 挨打方, 数值)` 会把 `damage()` 里那两道乘数一起乘进来（`ampF` / `vulnF`，和直接伤害共用同一份实现，不会再走岔）：

- **增伤**算在**打出这段伤害的人**身上：毒 / 流血是当初下毒 / 下血的那位，反击是弹出去的那位。所以「毒跳伤」现在会跟着下毒者的增伤走。
- **易伤**算在**挨打的人**身上，和直接伤害一致。
- 乘的是**结算那一刻**的数值：增伤 3 回合，就只管这 3 回合里跳的毒——和「挂上增伤后这 3 回合出手才变大」是同一套时序，不会出现「毒一次性吃满全程增伤」。
- 暴击仍然不作用于持续伤害（它们不掷骰子，`dot` / `counter` 事件永远 `crit: false`）；`pctHp` 比例扣血也照旧不乘增伤——它是「换掉防御」的真伤，不该再吃增伤的甜头。

顺带修掉的记账 bug：**毒每跳的伤害源原来是「对面随便找一位」**（`[...A,...E].find(x => x.side !== u.side)`，也就是数组里第一个阵营不同的单位，永远是**一号位**）。于是一整场里所有中毒伤害、连带的击杀，全记在一号位头上——结算页那一栏「持续伤害」一号位永远高得离谱，哪怕他根本不挂毒。现在毒的状态里记了 `by`（下毒者的 uid，跟着更强的那一次走），伤害、击杀、结算归属都回到真正下毒的人身上。流血本来就有 `by`，没这个问题。

体检（`tools/ai-bench.mjs` 同规模的 1460 场 A/B）：胜率 30.7% → 30.8%，伤害构成里持续伤害占比 14.2% → 14.4%。改动只在「有增伤 / 易伤挂着的回合」里生效，不挂的时候一分不差。

- 重甲那条域规提示同步改掉了：现在是「易伤 / 降防（毒 / 流血 / 反击一样要过防御），或者用比例伤害绕开防御」。

## 多段技能与屏障（`core/skills.js` 的 `hitsOfCard`）

屏障是「每层挡一次直接伤害」，可卡面上写着「造成 … 点伤害 **N 次**」的角色，以前全都没有真的打 N 下——`buildKit` 把卡面那句「N 次」整个丢掉了，一律只有一段。结果全游戏只有 Alice / 鼠王 那几个手写 kit 的角色能靠多段磨掉屏障，卡斯托尔、克莱门汀这些卡面明明是 3 段的，打上去跟单段角色一模一样。

现在 `buildKit` 从技能文本里读段数（`hitsOfCard`：匹配「伤害 N 次」，上限 3 段），把第一段伤害改成 `{ m: 总倍率 × 0.9 / N, hits: N }`：

- **总倍率打九折**：多段顺带绕开了「一次打太重的反震」（单段超过目标最大生命 7% 会被反震 35%），也给屏障这类按次数结算的机制开了后门，所以整体压 10% 平衡回来。1460 场 A/B 胜率 30.8% 不变。
- 覆盖 **25 / 62** 名官方角色（改造前只有 7 名手写 kit 是多段）。`tests/core.test.mjs` 里「多段技能逐段扣屏障」直接构造屏障木桩验证：3 段会产生 3 个伤害事件、前几段被屏障吃掉、最后一段真的打到血；同样的单段技能则整段被挡掉。

## 吸血（词条与技能）

- 来源：词条「吸血」（慈悲 4 件 15%、部分钥令、本命羁绊「血色节拍」6%）= 每次造成伤害，按**盾前伤害**的百分比治疗自己；技能里的「吸血 X%」= 按这次技能实际打出的伤害算。
- **满血溢出转护盾**：治疗补满后多出的部分变成自己的护盾（上限 = 最大生命的 30%），所以前排没受伤时吸血也不会白吃；治疗压制规则（91 关起）仍对它生效。
- 纯辅助技能（先治疗、没有伤害，如雷伊、沙耶的技能 1）没有可吸的伤害，按自身攻击力 ×1 当一次出手来算。

## 同调率（`core/affinity.js` + `ui/affinity.js`）

第二条养成线：等级 / 叠位 / 装备是「数值」，羁绊是「组队关系」，同调率认的是**你一直带着谁**。

- **怎么涨**：打赢一场，当前队伍四个人各 +1（第 40 关起 +2、第 80 关起 +3，首领关翻倍）；离线挂机也算，但压得克制——一场约 0.35 点、单次最多 60 点，睡一觉不会直接满级。每日跨天自动补 2 束花 + 1 张唱片进包；礼物也能用金币买（金币本来只喂升级，后期越攒越多，这里给它一个出口）。
- **等级**：Lv.1~10，累计点数 `AFF_STEPS = [0, 30, 70, 120, 180, 250, 330, 420, 520, 630]`。等级不单独存，一律从点数推——存两份迟早对不上。
- **天赋**（只作用于这个人）：Lv2 生命 +6% / Lv4 攻击 +6% / Lv6 防御 +10% / Lv8 暴击率 +5%、暴伤 +10% / **Lv10 卡牌特殊效果**。
- **Lv10 的卡牌效果**按定位挂在「技能一」上：突击「同调·贯穿」追加目标最大生命 8% 的真实伤害（不吃防御、不被屏障抵消）；守护「同调·壁垒」追加自身 2 层屏障；合唱「同调·和声」追加全队增伤 10% 两回合。实现是给 kit 追加一条 rider，**原 kit 不动**（全角色共用同一份 data.kit，改了会串味），结果按 `slug|type|技能等级` 缓存。
- 入口：更多 → 同调（礼物仓库 + 全员一览），以及每个唤醒体详情页里的「同调率」区块。

## 羁绊强化（`BOND_POWER`）

羁绊是白送的全队被动（不看站位、不看存活），上线时数值定得保守，结果「凑四条羁绊」的收益还不如一件密契套装。现在战斗类词条统一 ×1.4（`bonds.js` 的 `BOND_POWER`），**金币词条不乘**——那是经济，不该跟着战斗强度走。`teamBonds` 返回的 `bonus` 已经是乘过的值，所以详情页、战报、`bonusText` 显示的都是实战口径。

## 难度曲线：去掉三处尖峰

`tools/curve-audit.mjs` 会按「20/30/…/99 级」扫每一关的胜率，输出「几级能过这一关」。改之前最陡的三处：

1. **第 40/80/120 关（校猫奖励关）**：以前沿用 Boss 编成（校猫 + 米酒 + 一只普通怪），校猫本来就 5.5 倍血、米酒按精英档 2.2 倍血，等于一关塞了两只非普通怪。40 关需要的等级比 41 关高 30 级。现在奖励关只有「校猫 + 米酒」两只。
2. **第 9 关（关底前加压）**：那一关是 4 只怪，第 4 只按满编算，于是 49 关需要的等级比 48 关高 20 级。现在第 4 只改成偏脆的（血 65% / 攻 80%），加压保留、尖峰去掉。
3. **精英关**：精英血量倍率 2.4 → 2.2。

## 平衡审计（`tools/balance-audit.mjs`）

一次跑完两件事：① 每位唤醒体的胜率 / 伤害占比 / 存活率，按定位汇总并标出离群；② 五套队伍原型（毒 / 反击 / 多段 / 直伤 / 初始四人）的横向对比——用来回答「毒反在被改成吃防御 + 吃增伤之后还站不站得住」。

60 级 ★10、关卡 20/28/36/44/52 的结论（**这一节的数字是引入定位特性之前的**，本轮的对照表在下面「这一轮的全员审计」）：

- **毒队 100%（平均 8.2 回合）、反击队 100%（6.0）、初始四人 100%、多段队 93%、直伤队 93%**：毒 / 流血 / 反击吃过半量防御之后没有掉档，仍然是「打重甲」的正解；直伤队是最快的（3.9 回合）但最脆（平均只剩 3.47 人），四条路的取舍还在。
- **定位差**：突击 94.7%、合唱 86.4%、守护 **80.3%**（改之前 73%）。守护垫底不是因为它不耐打，而是挂机判负几乎都是「打满回合没清场」，纯堆防御对胜率毫无意义。所以给守护加了一条结构性补偿：**队伍里每有一位守护，全队增伤 +5%（最多 +10%）**，把「站得住才敢打」折算成输出。差从 21.7 个百分点收到 14.4。
- 离群角色：过强 20 位集中在高倍率单体突击（蚀灭·萝坦 61% 伤害占比），过弱 20 位基本是合唱 / 守护辅助位——这是定位口径差异（辅助的贡献在存活与治疗，不在伤害占比），没有按胜率硬拉平，只靠上面的守护掩护 + 羁绊系数托了一手。

## 定位特性：合唱的五种子定位（`core/roles.js`）

以前 24 个合唱（辅助）用的是同一套模板：普攻、架势、**技能一治疗、技能二给全队 +攻击**、大招治疗 + 充能。差别只在附带的 rider 上，于是「五个辅助」和「同一个辅助上五遍」在体验上没区别，编队时唯一的判断标准是谁面板高。

现在按**打法**再切五刀，换掉的是技能构成，不是名字：

| 子定位 | 技能一 | 技能二 | 大招 | 队伍光环 |
|---|---|---|---|---|
| 司疗 | 大治疗 + 小盾 | 群体治疗 + 小攻击 | 全队治疗 + 减伤 | 受疗 +12%、增伤 +4% |
| 咏唱 | 小治疗 + 攻击 | 全队攻击（最高一档） | 攻击 + 增伤 | 攻击 +6% |
| 击拍 | 伤害 + 治疗 | 暴击率 + 增伤 | 伤害 + 暴击 | 暴击伤害 +10% |
| 蚀咏 | 治疗 + 易伤 | 降防 + 降攻 | 群体伤害 + 易伤 | 增伤 +5%（持续伤害也吃） |
| 守律 | 治疗 + 全队盾 | 全队盾 + 防御 | 全队盾 + 治疗 | 护盾 +15%、增伤 +4% |

- **分派**：`CHORUS_OF` 一张表，按「档案里的打法标签 + 现有 kit 偏向」定；没登记的人落到「咏唱」（至少是能用的增益）。
- **光环**：队伍级、不看站位与存活，**同类最多叠 2 层**（`AURA_CAP`）—— 不封顶的话「四辅助」会靠光环滚雪球，把编队的取舍又压回一个解。
- **司疗 / 守律额外给 4% 增伤**：这两个子定位自己不出手，而挂机判负几乎都是「打满回合没清场」，纯续航在胜率上等于零贡献，所以把「队伍活得更久」折算一点推进力。
- 界面上：详情页顶部多一个「合唱 · 蚀咏」的标签，正文里有一块「定位特性」（含队伍光环）；队伍页每个槽位会显示两字的子定位（蚀 / 咏 / 击 / 律 / 疗）。

## 守护的「铁壁」与定位补正

- **铁壁**（`IRON_GUARD`）：纯盾型守护（护盾堆得最厚、伤害最低的那十位）在挂机里是负资产。现在它们回合结束时把这一回合**没被消耗掉的护盾**按比例砸回去（走 `guarded`，吃半量防御、吃增伤与易伤），并给被砸中的敌人挂「降防 15% / 2 回合」。只加反震实测每回合才 19 点，等于没加；真正让它有意义的是降防——守护的贡献不是自己那点伤害，而是让全队打得更快。

## 装备小特质（器纹 / 特质）审计

- 命轮「器纹」和造物「特质」是按 id 哈希挂的一条固定小加成（起手共鸣 / 起手钥焰 / 吸血 / 濒死存活 / 金币 / 首击增伤 / 增伤 / 治疗）。
- ~~暴击系装备固定带起手钥焰~~（已取消）：初始属性现在一律**随机**，见下面「初始属性」。
- 修了一个哈希耦合：造物主题 `hash % 10` 与特质 `hash % 8` 的奇偶连在一起，每个主题只能抽到 8 种特质里的 4 种（例如祝福永远没有首击增伤）；特质现在先过整数混合器再取模，十个主题都能抽到全部 8 种。已有装备的特质因此会重新分配（只是 +2~8 的小加成，不吃等级与精炼）。

## 器纹 / 特质刷取（命轮 + 造物）

- 命轮叫「器纹」、造物叫「特质」，**同一套刷取规则**：造物列表每件有「特质」按钮，造物详情里也有；候选、价格、品阶、16 种属性都一样。造物同样按稀有度（N / SR / SSR）乘价格。

- 命轮列表每件有「器纹」按钮（刷过的会标品阶）：**花金币随机刷**，抽到的是**候选**，可「换上新的」或「保留原来的」（金币不退）。
- **16 种属性**随机：攻击 / 生命 / 防御 / 暴击率 / 暴击伤害 / 增伤 / 共鸣回复 / 钥焰回复 / 治疗 / 护盾 / 吸血 / 濒死存活 / 起始共鸣 / 起始钥焰 / 首击增伤 / 金币（正好是加成池的全部 16 个字段）。
- **5 个品阶**：凡 ×0.5（40%）/ 良 ×0.75（30%）/ 精 ×1（18%）/ 极 ×1.5（9%）/ 绝 ×2.2（3%）。「精」档的数值 = 旧的固定器纹，所以没刷过的命轮数值完全不变（按哈希出的那一条、精档计）。
- 价格 = 约 12 场胜利的金币（`stageGold(最高通关关) × 12`）× 稀有度（N 0.5 / R 0.7 / SR 1 / SSR 1.4），随进度涨，最低 300。
- 器纹是固定小加成，不吃强化等级与精炼；装备回溯不会重置器纹。
- 暴击系命轮出厂器纹固定是起手钥焰（见上一节），刷过之后按新器纹算。

## 濒死存活（死亡抵抗）

- 致命一击按「濒死存活」概率挡成剩 1 点血。**触发一次后这个单位的概率折半，可以连续触发**（0.9 → 0.45 → 0.225 …，低于 0.1% 归零），不再是整场只能救一次。概率按单位各算各的，场与场之间重新开始。

## 初始属性随机

- 命轮的器纹 / 造物的特质**不再是按 id 固定的一条**：装备获得的那一刻就随机抽（16 种属性 × 5 个品阶，概率同刷取：凡 40% / 良 30% / 精 18% / 极 9% / 绝 3%），存在装备自己身上（`it.rune`）。
- 按「装备编号 + 存档种子」播种：同一件装备读档后不变，换存档或换装备各不相同。
- 老存档迁移时，没有 `rune` 的命轮 / 造物补抽一次（之后存进档里不再变）；之前「暴击装备固定起手钥焰」随之取消。
- 抽到不满意的，照旧可以花金币刷取。

## 云存档与装备词条

- 云存档上传时把装备「压扁」成数组（省体积）。之前只存了前五列，**命轮器纹 / 造物特质（`it.rune`）和没决定的候选（`it.runeNew`）在上传时被丢掉**，换设备拉回来词条全没了，再被迁移随机补一遍——等于换设备就重新随机。现在压扁格式多两列（`[属性, 品阶]`），读出来原样展开；老格式（五列）照常能读。

## 大运：重掷与治疗的两处修复

- **重掷没用**：候选池的随机种子只有「第几层 / 第几格 / 打了几场」，同一个节点里重掷用的种子完全一样，每次出来的都是同一批。现在种子带上「已重掷次数」，并且重掷时尽量排开上一批里出现过的造物 / 强化 / 增益。
- **治疗把倒下的人救活**：「涌泉 / 慈悲之证 / 复盘天赋」的战后回血、事件里的治疗、商店的热汤、过层回血，对血量 0 的队员也会加上血，等于每次战后都免费复活。现在回血只作用在还活着的人身上；真正的复活只有「不灭余烬」（每层一次）。
