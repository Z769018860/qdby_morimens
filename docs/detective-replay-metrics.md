# 战报侦探 · 回放实测数据（钥令开启次数 / 侵蚀伤害）

> 这两项**都不在榜单摘要里**（`battle-summary` 32 个字段到 `maxPosion` 为止），只能从战斗回放本体里量。
> 回放不是 JSON，是 LZ4 帧 + MessagePack，解码用仓库里的 `js/replay.js`。
> 
> - **钥令开启次数** = `statistics.UsedKeeperSkillCount`。`battleDat.statistics` 是「进首领房那一刻」的快照，
>   首领那几回合还没算进去，所以取帧日志里回合数最大的那份 `globalStats`。
> - **侵蚀伤害** = 回放最后一版逐状态统计里 `state[*].AwakerDoDamage`，状态名含「侵蚀」的那些求和。
>   和摘要里的 `maxPosion`（中毒）不是一个东西：中毒是层数峰值，侵蚀是累计伤害。

## 已知问题

- 回放统计是客户端写的，个别场次会缺字段；缺的题不写这项，卡片上就不显示，不做估算。
- 侵蚀伤害只在「队里真的有人打侵蚀」时非零；0 分两种情况——真没打，或这份回放的逐状态统计没录，
  所以只有逐状态统计存在（stateDmg > 0）时才把 0 当成真 0。
